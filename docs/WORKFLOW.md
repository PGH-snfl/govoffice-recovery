# 복구 작업 흐름

## 모듈 하나를 복구하는 기준 절차

1. `pyz_modules/`의 원본 `.marshal`을 선택한다.
2. 코드 객체 목록, 문자열, import, 디스어셈블을 생성한다.
3. `decompiled_modules/`의 자동 역컴파일 결과와 함수별로 비교한다.
4. 공개 이름과 인자 순서를 유지해 `recovered/`에 다시 작성한다.
5. 확정할 수 없는 분기는 추측해 숨기지 않고 주석과 작업 기록에 남긴다.
6. 문법 검사와 공개 API 비교를 수행한다.
7. 외부 프로그램 없이 모의 객체로 호출 순서를 시험한다.
8. 마지막 단계에서만 실제 Office COM 통합 시험을 수행한다.

## 우선순위

1. 공통 인터페이스와 리소스 경로
2. PowerPoint 기본 객체 조작
3. 메인 GUI의 import와 프레임 구성
4. Excel 연결 및 범위 처리
5. 한컴 기본 연결 및 문서 조작
6. 기관별·업무별 자동화 기능
