# 내부 협업 인계 점검 — 2026-09-29

## 공유 범위

기존 비공개 저장소 `PGH-snfl/govoffice-recovery`의 `main`을 사용한다. 저장소 공개 범위는 변경하지 않는다. 현재 실행 코드, 한글 기본·기관·개인 기능, 작성·양식 분석·출력 보정, 복구 근거, 기본 양식, 검사 코드와 작성 레퍼런스 기억을 저장한다.

루트의 `시작전_점검.cmd`, `범정부오피스_실행.cmd`, `전체검사.cmd`와 [시작 안내](GETTING_STARTED.md)를 제공한다. 전체 저장소에 Python 3.13과 연결 라이브러리가 포함돼 있으므로 새 PC에서 개발용 Python을 따로 구성할 필요 없이 기본 점검을 시작할 수 있다. 데스크톱 한글 설치와 선택적 인공지능 계정 연결은 별도다.

## 데이터 보호

개인 정보·즐겨찾기·등록 양식·실제 작성 이력·응답 묶음·검증 화면·로컬 백업은 업로드하지 않는다. 실제 작업 문서는 로컬에 그대로 보존한다. `materials/`는 기존 일반 예시 2개와 기본 빈 양식, 폴더 안내만 공유한다. 기본 기관 양식과 실행에 필요한 원본 구조 데이터는 프로그램 자원에 포함한다.

대용량 실제 한글 문서(165,536,256바이트)는 삭제하지 않고 공유 제외했다. 레퍼런스 조사용 공식 공개 보고서와 조사 기록은 별도 연구 근거이며 사용자 개인정보 저장소와 다르다. 과거 로그의 로컬 경로와 사용자 전용 자료 링크는 기록으로 남아 있을 수 있다.

## 검증 상태

- 디렉터리 정리: 이동 파일 72개 내용 일치, 구조·경로 검사 12개 통과.
- 작업 폴더 전체 자동검사: 605개 실행, 실패·오류 0, 환경 조건에 따른 2개 건너뜀.
- 새 시작 점검기의 파일·Python·화면·인코딩·쓰기 가능 검사 통과.
- Git에 담긴 파일만 별도의 빈 폴더에 꺼낸 뒤 환경 점검·기능 목록 조회 통과. 새 임시 사용자 데이터로 전체 자동검사 **606개 실행, 604개 통과, 실패·오류 0, 2개 건너뜀**(51.346초).
- 건너뛴 2개는 개인 원문 기반 HWPML 회귀시험 자료가 설치되어 있지 않아 제외된 항목이다. 실패를 숨기거나 실제 한글 전 기능 검증으로 바꾸어 표현하지 않는다.
- 현재 PC에서 문서를 열지 않는 한글 설치 등록·보안 모듈 비트수 점검도 통과했다. 새 PC에서는 같은 시작 점검을 다시 해야 한다.
- 최종 파일 목록 11,912개(약 1.28GB)에 대해 100MiB 이상 단일 파일 0개, 개인 데이터 경로 0개, 검사한 텍스트의 인증키 패턴 후보 0개, 읽지 못한 파일 0개를 확인했다. 정규식·경로 검사는 전체 개인정보의 완전한 탐지 또는 과거 Git 이력의 전수 감사가 아니다.

새 폴더 첫 검증에서 기존 `*.py[cod]` 제외 규칙이 실행용 `.pyd` 확장 모듈까지 제외한 문제를 확인했다. 제외 대상을 `.pyc`·`.pyo` 캐시로 제한하고 실제 `.pyd`를 저장소에 포함했다. 동일 문제가 재발하지 않도록 필수 모듈 존재 검사도 추가했다. 양식 원문의 해시가 줄바꿈 자동 변환으로 달라지지 않도록 `.hwpml`·`.hml`도 원본 바이트를 보존한다.

개인정보가 없는 버튼 연결 검증 요약 `button_binding_verification.json`은 자동검사에 필요하므로 공유 목록에 명시적으로 포함했다. 실제 사용자 문서가 있는 나머지 검증 묶음을 일괄 공개하지 않는다.

자동검사는 모의 한글 객체, 데이터 변환, 화면 구조·이벤트 등을 포함한다. 실제 다른 PC에서 한글 문서를 열고 저장하는 전 기능 시험은 아니다. 최종 인계에서도 ‘모든 문서가 즉시 제출 가능’ 또는 ‘모든 PC에서 호환 보장’으로 표현하지 않는다.

## 남은 환경별 확인

1. 새 PC의 한글 설치·자동화 등록·보안 모듈 비트수·권한 조건.
2. 선택 기능인 인공지능의 사용자 본인 로그인과 사용 가능 여부.
3. 실제 문서의 입력 위치·서식·분량·수식 배치 및 결과 내용 검토.
4. 조사 원문의 모든 시각자료 개별 검증은 아직 미완료다. 기존 기억 파일의 확인 수준을 유지한다.

내부 협업 인계 시점의 코드 저장이며 위 제한까지 해결됐다는 의미의 무조건적인 ‘최종 완성’은 아니다.
