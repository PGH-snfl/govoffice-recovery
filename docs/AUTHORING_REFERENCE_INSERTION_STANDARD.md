# 연구개발 문서 참고자료 삽입 기준

정리일: 2026-09-26. 범정부오피스 내부 문서 작성용 기준이다. 정부의 공식 심사기준이 아니며 **사용자 양식에 적힌 실제 작성요령·분량·표 요구가 우선**한다.

여기서 참고자료는 본문에 넣는 사진·화면·표·그래프·구성도·절차도와 그 출처를 뜻한다. 타 과제에서 가져올 것은 설명 방식이지 타 과제의 실적·사진·수치를 사용자 실적으로 바꾸는 것이 아니다.

## 1. 넣을지 결정하는 기준

아래 순서로 판단한다. 항목마다 그림을 의무적으로 만들거나 그림 개수로 완성도를 판단하지 않는다.

1. **양식 요구**: 해당 소주제에서 반드시 작성하도록 지정한 표·도식은 우선 작성한다. 정보가 없으면 미확정으로 남기고 확정 사실처럼 채우지 않는다.
2. **설명할 주장**: “이 자료로 무엇을 이해·비교·확인하게 할 것인가?”를 한 문장으로 쓴다. 목적을 쓸 수 없으면 빼는 것이 원칙이다.
3. **필요성**: 관계·순서·조건별 차이·실물 상태를 글보다 명확히 보여주는가? 한 문장으로 충분하면 문장으로 쓴다.
4. **근거**: 실제 제공 자료, 확인 가능한 외부 출처, 사용자 연구계획 중 어디에 해당하는가? 근거 없는 측정값·사진·협력관계는 만들지 않는다.
5. **본문 연결**: 앞 문단의 주장과 이어지고 뒤 문단에서 의미를 해석할 수 있는가? 본문에 언급되지 않는 장식 이미지는 제외한다.
6. **가독성과 분량**: 최종 한글 문서에서 글씨·범례·단위가 읽히는가? 안 읽히면 확대·분할·요약하고 상세는 허용되는 부록으로 옮긴다. 양식의 표나 쪽 제한을 임의로 바꾸지 않는다.

판정은 `삽입 가능 / 자료 보완 후 삽입 / 생략`으로 남긴다. 점수만으로 자동 결정하지 않는다. 필요한 자료는 한 번에 모아서 확인하고, 근거가 있는 부분은 먼저 작성한다.

## 2. 설명 목적에 맞는 형식

| 설명할 것 | 우선 검토할 형식 | 반드시 있어야 할 내용 | 피할 것 |
|---|---|---|---|
| 실제 현장의 문제·장비 상태 | 사진 + 필요한 부분 주석 | 촬영 대상·시점·문제 위치, 자체/외부 자료 구분 | 분위기용 사진, 외부 제품을 자체 시제품으로 표기 |
| 여러 대안의 차이 | 비교표 또는 같은 조건의 비교 이미지 | 공통 비교항목, 조건·단위·출처, 미확인 표시 | 유리한 항목만 서로 다른 기준으로 비교 |
| 구성요소와 개발 범위 | 구성도 | 입력·처리·출력, 연결 의미, 개발/기존/외부 영역 구분 | 화살표 의미 없는 상자 나열 |
| 처리·실험·업무 순서 | 절차도 | 시작·단계·조건 분기·실패 처리·완료 산출물 | 순환 구조를 직선 단계로 오해하게 표현 |
| 주체 사이 요청·응답 순서 | 주체별 세로 열과 시간순 화살표 | 주체, 메시지, 순서, 성공/오류 응답 | 기술 구성도와 시간순 절차 혼합 |
| 연도별 개발·완료 조건 | 연차표 또는 일정 막대 도표 | 작업·기간·선행 산출물·완료 기준·담당 | 근거 없이 모든 작업을 동시에 배치 |
| 기관의 책임·협업 | 역할표 + 필요한 관계도 | 작업·주관·협력·자료 전달·산출물 | 확인되지 않은 기관을 협약 파트너로 표기 |
| 실제 수치의 변화·분포 | 선/막대/산점도 등 그래프 | 원자료, 축·단위·범례·조건·비교 기준 | 숫자 없이 그럴듯한 상승 곡선 생성 |
| 정확한 수치·사양·평가 기준 | 표 | 지표·값·단위·조건·근거 | 그래프로만 보여 정확한 값 확인 불가 |
| 입력→처리→결과의 차이 | 같은 크기의 단계별 이미지 | 입력/처리/정답 또는 전/후 구분, 동일 대상 | 서로 다른 사례를 처리 전후로 오인하게 배치 |
| 구현된 기능의 사용 방식 | 실제 화면 + 단계 번호 | 버전·환경·입력·결과, 필요한 영역 확대 | 설계 시안을 실제 작동 화면처럼 표기 |
| 선행성과·인증·시험 증빙 | 핵심사항 표 + 증빙 발췌 | 기관·일자·대상·범위·문서 식별정보 | 증빙 표지 축소판만 붙이고 성능 입증 주장 |

구성도는 관계, 절차도는 순서, 역할표는 책임, 일정표는 시간을 설명한다. 같은 그림의 제목만 바꿔 반복하지 않는다.

## 4. 표에 담을 내용의 최소 기준

- **차별성 표**: 비교대상 / 동일 비교항목 / 기존 상태와 출처 / 제안 내용 / 개선을 확인할 방법. 아직 검증하지 않은 차이는 ‘목표’ 또는 ‘설계상 차이’로 표시한다.
- **정량목표 표**: 세부목표 / 지표 정의 / 단위 / 시작 기준과 근거 / 연차별 목표 / 시험조건 / 평가방법 / 판정 주체. 양식이 요구하지 않는 열은 설명 필요성에 따라 줄인다.
- **연차표**: 작업 / 선행 입력 / 해당 연차 수행내용 / 산출물 / 완료 기준 / 담당. 같은 산출물 이름을 목표·본문·평가표에서도 사용한다.
- **데이터 표**: 항목명 / 의미 / 형식 / 수집원 / 활용 목적 / 수량 또는 산정 계획 / 품질 확인 / 접근·사용 조건. 실제 개인 식별값을 예시 데이터처럼 재사용하지 않는다.
- **시험표**: 검증 주장 / 비교대상 / 시험환경 / 변경 조건 / 고정 조건 / 측정 지표 / 반복·표본 계획 / 합격 기준. 수행 전에는 결과 대신 시험계획을 쓴다.
- **기관 역할표**: 세부작업 / 책임 주체 / 협력 주체 / 제공·인수 자료 / 산출물 / 협의 상태. 미협의는 미협의라고 적는다.
- **활용표**: 결과물 / 실제 또는 예상 수요자 / 적용 장면 / 후속 개발·인증·운영 조건 / 활용 시기 / 확인 근거. 계획과 계약·판매 실적을 구분한다.

여러 하위 값이 하나의 상위 항목에 속할 때만 상위 셀을 병합한다. 서로 다른 단위·시험조건까지 병합하여 의미를 잃게 하지 않는다. 페이지를 넘는 표에는 가능한 범위에서 머리글을 반복하고, 문서 양식의 행 높이·병합 구조와 충돌하는지 확인한다.

## 5. 본문과 자료를 연결하는 방식

기본 연결은 **설명할 주장 → 자료 → 핵심 해석과 연구 연결**이다. 원본 양식이 다른 배치를 요구하면 양식을 따른다.

예시 — 사용자가 실제 처리 단계를 제공한 문서 자동작성 연구:

> 본 연구는 양식의 항목 구조를 확인하는 단계와 본문을 작성하는 단계를 구분한다. 그림 1은 입력 문서에서 결과 검토까지의 계획된 처리 관계를 나타낸다.
>
> [사용자가 제공한 단계만으로 만든 구성도: 입력 문서 → 항목 확인 → 근거자료 연결 → 본문 초안 → 사용자 검토]
>
> 항목 확인 결과를 작성 단계에 전달해 양식 누락을 줄이고, 출력 전에 사용자가 내용과 근거를 검토하도록 설계한다.

이 예시는 설계 설명이지 현재 프로그램의 구현 완료·성능 입증이 아니다. 정확도나 처리시간이 없는데 숫자를 넣거나 개선률 그래프를 만들지 않는다.

- 캡션(그림·표 제목)은 대상과 관점을 담는다. ‘시스템 구성도’보다 ‘입력 문서에서 항목별 초안 생성까지의 처리 구성(계획)’처럼 구체화한다.
- 제목의 위/아래 위치는 양식과 문서 내 일관성을 따른다. 무조건 한 위치라고 단정하지 않는다.
- 본문에서 번호로 참조하고 무엇을 봐야 하는지 설명한다. “아래 그림 참조”만 쓰지 않는다.
- 자료 뒤에는 핵심 차이·이유·한계·다음 연구와의 관계를 해석한다. 표의 모든 셀을 문장으로 다시 읽어주지 않는다.
- 그림 번호, 본문 참조, 캡션, 실제 내용이 일치해야 한다. 한글 파일로 출력한 후 잘림·쪽 나눔·글씨 크기·표 넘침을 확인한다.

## 6. 근거 수준과 출처 표시

| 자료 상태 | 문서에서의 표현 | 금지되는 바꾸기 |
|---|---|---|
| 사용자 과제의 실제 측정·실물·실행 화면 | 수행 시점·조건을 갖춘 실제 결과 | 조건을 숨기거나 성능을 임의 보정 |
| 사용자가 설명한 연구계획 | ‘계획’, ‘목표’, ‘개념도’, ‘설계안’ | 제작 완료·검증 완료로 서술 |
| 외부 논문·공개 보고서의 결과 | 외부 사례·선행연구로 출처 표기 | 기관명만 사용자 기관으로 교체 |
| 외부 사진·제품·화면 | 외부 사례, 원출처와 이용 조건 확인 | 사용자 보유 장비·자체 시제품으로 표시 |
| 조사자의 캡션 기반 분류 | 검색·후보 선정에만 사용 | 지면을 직접 확인한 것처럼 확정 |
| 근거·원자료 미확보 | 자료 필요, 보완 대기 또는 생략 | 그럴듯한 수치·증빙 생성 |

출처에는 가능한 범위에서 **자료명·작성기관/저자·연도·해당 쪽/표·그림 번호·원문 주소**를 남긴다. 변동되는 웹 자료에는 확인일도 남긴다. 원문 그림 사용, 일부 발췌, 내용을 재구성한 자체 도식은 서로 구분한다. 출처 표시만으로 모든 이미지의 재사용이 허용되는 것은 아니므로 이용 조건을 확인한다. 외부 수치에 다시 계산을 적용했다면 원자료와 산식·가정을 남긴다.

계획서에서 최종보고서를 참고할 때는 특히 **완료된 실적→수행하려는 방법**, **달성 결과→평가할 지표와 절차**로 참고 범위를 바꿔야 한다. ‘미래 활용 목표’가 적힌 표는 완료 실적이 아니다(I39 106쪽). 행사 사진은 활동 증빙이지 기술 성능 증빙이 아니다(I05 27쪽).

## 7. 자료가 없을 때의 처리

| 없는 자료 | 가능한 처리 | 하지 않을 것 |
|---|---|---|
| 자체 시제품 사진 | 사용자 계획에 근거한 구성도·설계안, 계획 표시 | 가짜 실물 사진을 만들어 제작 증거로 사용 |
| 측정 결과 | 지표·조건·평가방법 표 | 임의 성능 그래프·달성률 |
| 목표 수치의 근거 | 산정 근거 보완 요청, 미확정 표시 | 참고 과제 수치를 그대로 목표로 복사 |
| 현재 화면 | 기능 흐름 설명 또는 ‘화면 설계안’ | 설계 시안을 실제 실행 결과로 표시 |
| 협력·수요 확인 | 예상 활용 대상과 협의 필요사항 | 존재하지 않는 협약·도입 확정 문구 |
| 외부 이미지 이용 확인 | 자체 재구성한 설명 도식 또는 글로 요약, 원근거 표기 | 출처만 달면 무조건 사용 가능하다고 판단 |

미확정 자료를 표시한 초안과 제출 가능한 완성본은 구분한다. 최종본에는 보완 대기 표시가 남아 있는지 확인하고, 필수 항목이 비어 있으면 제출 준비 완료라고 안내하지 않는다.

## 8. 가독성·개인정보·검증 기준

- 그래프: 축·단위·범례·조건·대상·표본/반복 정보 중 해석에 필요한 내용을 표시한다. 다른 조건의 값을 같은 조건인 것처럼 연결하지 않는다.
- 비교 이미지: 동일 크기·순서·배율·표시 기준을 사용한다. 가능한 경우 원본/처리/정답 또는 전/후를 같은 행에 둔다.
- 사진·화면: 설명에 필요한 영역을 확대하고 주석을 붙인다. 개인정보·인증정보를 가릴 때는 비식별 처리 사실을 남기고 결과 자체를 변조하지 않는다.
- 큰 구성도: 전체 개요와 부분도로 나눈다. 세로로 돌린 복잡한 그림을 표 셀에 축소해 넣는 방식은 세부 판독이 어려울 수 있다(I44 19쪽).
- 증빙: 표지·논문 전체 페이지의 축소판만으로 세부 기술을 설명하지 않는다. 필요한 핵심 항목을 본문에서 설명하고 허용되는 부록에 원증빙을 연결한다(S09의 첨부 논문·공정표 사례).
- 수치: 본문·표·그래프·예산·연차 간 값과 단위가 일치하는지 대조한다. 빈칸을 0으로 바꾸지 않는다.
- 최종 검토: 사용자가 주지 않은 실적·측정값·기관·사진이 추가되지 않았는지, 외부 자료와 자체 계획이 명확한지 확인한다.

## 9. 이후 작성 때 남길 삽입 기록

각 자료마다 다음 기록을 남긴다. 내부 작업 기록이며 사용자 문서 본문에 이 항목을 전부 출력하지는 않는다.

```text
문서 소주제·삽입 위치:
설명할 주장:
자료가 필요한 이유:
형식과 구성 항목:
사용자에게서 확보한 실제 정보:
추가로 필요한 자료:
근거 상태: 자체 실측 / 사용자 계획 / 외부 사례 / 미확인
참고한 사례 번호·원문 쪽:
실제 자료 출처·이용 확인:
캡션·앞 문장·뒤 해석:
판정: 삽입 가능 / 보완 대기 / 생략
최종 한글 출력 확인:
```

이 기록은 ‘무엇을 어디에 왜 넣는지’와 ‘어디까지 사실인지’를 함께 추적하기 위한 것이다. 자동작성 코드에 연결한 것은 아니다.

## 10. 이번 조사 범위와 남은 작업

- 90건, 총 10,333쪽의 원문을 대상으로 텍스트·문서 내부 이미지 구성을 전 쪽 기계 점검했다.
- 번호 없는 괄호형 제목까지 탐색하여 캡션 후보 9,768개를 기록했다. 목차·중복·본문 언급·소제목 오탐이 포함되므로 고유 그림 수가 아니다. S05 2쪽과 S06 53쪽에서 글 중심 소제목이 후보에 섞인 것을 실제 확인했다.
- 실제 지면의 배치·설명 방식을 본 쪽은 누적 596쪽이다. 이번에 131개 지면을 추가 확인했으며 이전 검토와의 중복 8쪽을 빼면 123쪽 증가했다.
- 공개 목록이 없던 13건도 추가 확인했다. 불확실한 위치 후보와 추출 글자가 적은 스캔 지면을 별도로 검토했다. 그러나 목록 69개의 위치를 모두 개별 확정한 것은 아니다.
- **전체 시각자료의 개별 의미·정확한 위치·세부 수치를 전수 확인한 것은 아니다.** 미검토 9,737쪽과 개별 확인이 필요한 요소는 계속 남겨 둔다.
