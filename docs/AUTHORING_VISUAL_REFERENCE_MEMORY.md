# 연구개발 문서의 사진·표·그림 사용 기억

저장일: 2026-09-25, 추가 조사·기준 정리: 2026-09-26. 사용자 요청: 기존 레퍼런스에서 **어디에, 어떤 형식으로, 무엇을 설명하려고** 시각자료를 넣었는지 조사하여 이후 작성에 참고한다.

## 확인 범위 — 전수 검증 완료와 혼동하지 않기

- 기존 90건의 공식 공개 보고서 원문을 확보했다. 합계 10,333쪽이다. 90건 모두 실제 제출 제안서라는 뜻은 아니다.
- 77건의 공개 페이지에서 표·그림 목록 총 4,947개를 확보했다. 나머지 13건은 공개 목록이 없으며 **그림이 없다는 뜻이 아니다**.
- 목록 중 4,878개는 캡션 텍스트를 원문 쪽과 대조했다. 나머지 69개는 위치가 파일명 단서 등에 머무르며 확정하지 않았다.
- 90건 모두 대표 지면을 직접 보았고, 중복을 제외한 실제 검토 지면은 **596쪽**이다. 기존 473쪽에 이번 131쪽 중 중복 8쪽을 제외한 123쪽이 추가됐다. 원문 모든 쪽·모든 그림의 배치와 의미를 전수 검증한 것은 아니다. 미검토 지면 9,737쪽을 별도 기록했다.
- 전체 10,333쪽의 텍스트·문서 내부 구성을 기계 점검했다. 번호 없는 괄호형 제목까지 포함한 캡션 후보는 9,768개다(기존 탐색 6,336개). 목차·본문 언급·중복·소제목 오탐이 포함되므로 4,947개에 합산하거나 추가 그림 수로 주장하지 않는다.
- 문서 내부 큰 이미지 객체 15,509개는 고유 시각자료 개수가 아니다. 로고·스캔 지면·분할 이미지가 포함되고 선/글자 도식은 이 개수로 잡히지 않는다. 기계 점검 오류 0건은 의미 검증 완료라는 뜻이 아니다.
- 목록의 `format_candidate`와 `explanatory_purpose_candidate`는 **캡션 규칙 기반 추정**이다. 실제 지면에서 관찰한 설명과 혼동하지 않는다. 작은 지면 모음으로 확인한 것은 전체 배치와 설명 방식이며 미세 수치·모든 패널을 정독했다는 뜻이 아니다.

## 자료를 찾는 순서

1. [90건 사례별 기억](authoring_visual_reference_memory.json)에서 과제 성격과 소주제에 맞는 사례를 찾는다.
2. [사례별 조사 색인](../exa-results/reference-visuals-2026-09-25/README.md)에서 해당 보고서의 관찰 기록과 전체 공개 그림 목록을 연다.
3. 개별 그림의 정밀 활용이 필요하면 연결된 원문 PDF 해당 쪽을 다시 확인한다. 여기서 쪽수는 인쇄 쪽수가 아닌 **PDF 1부터 시작하는 쪽수**다.
4. [전체 시각자료 목록](../exa-results/reference-visuals-2026-09-25/visual_inventory.json), [검토 범위 집계](../exa-results/reference-visuals-2026-09-25/review_coverage.json), [미검토 쪽 목록](../exa-results/reference-visuals-2026-09-25/remaining_review.json)을 통해 확인 수준을 추적한다.
5. 실제 작성에서는 [참고자료 삽입 기준](AUTHORING_REFERENCE_INSERTION_STANDARD.md)을 적용한다. [추가 조사 색인](../exa-results/reference-visuals-2026-09-25/followup-2026-09-26/README.md)에는 90건 전체 쪽의 검색 단서, 확장 캡션 후보와 앞뒤 문맥, 추가 직접 관찰을 분리해 두었다.

## 2026-09-26 추가 조사에서 기억할 점

- 공개 목록이 없던 13건에서도 42쪽을 추가 관찰했다. 번호 없는 캡션으로 구성도·목표표·자료 사전·시험 장면을 설명하는 사례가 있었다. 괄호형 소제목만 있는 글 지면도 있어 자동 후보를 전부 그림으로 분류하면 안 된다(S05 2쪽, S06 53쪽).
- 위치 불확실 후보와 추출 텍스트가 적은 지면 89쪽을 추가 확인했다. 스캔된 논문·공정표·부록도 포함된다. 해당 페이지를 보았다고 공개 목록 69개의 캡션 위치를 모두 개별 확정한 것은 아니다.
- 개발범위 경계(I39 11쪽), 자료 정의와 학습/검증/시험 분할(I36 28쪽), 조건→장치→결과(S18 18쪽), 시나리오→반응 곡선(S23 23쪽), 지표→연차 목표→평가방법(S06 477쪽)의 대응 방식을 이후 계획서에 참고한다.
- 최종보고서의 실제 측정 결과와 계획서의 목표는 다르다. 사용자가 실측 자료를 주지 않으면 평가계획표를 작성하고 결과 그래프를 만들지 않는다. 행사 사진은 활동 증빙이며 성능 증빙이 아니다.

### 서울과기대 사례를 참고할 때

I48은 같은 과제 안에서도 서비스 개념(8쪽), 기술 흐름·기관 역할(14쪽), 연차(15쪽), 시연 화면(19쪽), 기하 원리·구현 흐름(25쪽), 처리 원리와 실제 파노라마 결과(58쪽)를 서로 다른 시각자료로 설명한다. 이후 사용자 연구도 ‘그림 하나로 전부 설명’하지 않고 실제 소주제에 맞춰 필요한 경우에만 구분한다.

## 다른 과제 성격에서 참고할 방식

- **소재·소자**: 제작 단계 모식도→현미경 사진→특성곡선을 연결한다. S12 10~12쪽, S17 7·10·11쪽. 축척, 조건, 대조군을 빼면 증거가 약해진다.
- **생명·의료 연구**: 작용기전 도식과 실험 사진/정량 그래프를 구분한다. 조건별 영상을 행렬로 배치하고 정량 결과를 대응한다. S13 21·26쪽, S14 9쪽, S37 9·12쪽.
- **로봇·기계**: 사양 비교표 안에 설계 이미지를 넣고, 부품 주석도·제어도·시뮬레이터를 별도 대응한다. S21 5·7쪽.
- **에너지·경제성**: 원료→공정→제품 흐름도와 가격 조건별 단가 행렬/시나리오 막대그래프를 구분한다. S19 76·100쪽.
- **공공 인프라 기획**: 현황표로 문제 규모를, 전체 개념도로 통합 범위를, 지표/단위/목표/평가방법 표로 검증을 설명한다. S29 63·100·140쪽.

## 표와 이미지의 형식에서 기억할 세부사항

- 여러 값이 같은 항목에 속하면 대표 항목 셀을 병합한다. 목표/실적, 조건/대조군은 같은 기준으로 정렬한다.
- 비교 이미지는 동일 크기·순서·조건 표기를 사용한다. 원본/처리/정답인지, 전/후인지 명확히 쓴다.
- 실제 장비 사진에는 위치·부품 화살표, 현미경 사진에는 축척, 그래프에는 단위·범례·시험조건을 넣는다.
- 구조도는 구성과 연결, 흐름도는 순서, 조직도는 책임, 연차도는 시점을 설명한다. 이름만 다른 같은 그림을 반복하지 않는다.
- 원문에도 그림 제목을 표 머리글처럼 위에 둔 사례(I50 7·9·11쪽)가 있다. ‘그림 제목은 무조건 아래’ 같은 규칙을 만들어 사용자 양식을 덮어쓰지 않는다.
- 논문·특허·인증서 축소판은 성과 증빙이지 연구원리를 설명하는 그림이 아니다. 비어 있는 양식표도 결과값으로 해석하지 않는다.
- 사진이 자체 실험물인지, 외부 제품인지, 현장 예시인지, 개념 비유인지 구분한다. I42 9쪽의 자동차 충돌 사진은 소프트웨어 시험을 설명하는 비유다.

## 사용자가 과제 내용을 주면 적용하는 순서

1. 실제 양식의 소주제와 작성요령을 우선한다. 그림/표 요구와 분량 제한을 확인한다.
2. 그 항목에서 설명할 핵심을 한 문장으로 정한다. 비교, 관계, 순서, 구조, 실증 중 무엇이 필요한지 판단한다. 단순한 문장은 억지로 그림으로 만들지 않는다.
3. 과제 성격이 가까운 사례의 해당 쪽을 고른다. 내용·실적을 가져오는 것이 아니라 설명 방식만 참고한다.
4. 삽입안을 `소주제 / 앞뒤 문단 / 설명 목적 / 형식 / 구성 항목 / 필요한 실제 자료 / 출처·확인 상태`로 정리한다.
5. 사용자 제공 내용만으로 가능한 구조도·역할표·연차표는 작성한다. 실제 현장 사진·측정값·시험성적서는 지어내지 않는다. 미제공이면 필요한 자료를 모아 알리거나 계획 도식으로 명확하게 구분한다.
6. 본문이 그림/표를 소개하고 그 뒤 핵심 해석을 하도록 연결한다. 그림만 붙여 놓거나 동일 내용을 장황하게 반복하지 않는다.
7. 타 과제의 사진·수치·기관·실적을 사용자 과제의 결과로 바꾸지 않는다. 제3자 자료의 재사용은 출처와 이용 조건을 확인한다.

## 아직 남은 조사

사용자가 요구한 ‘전부’는 **모든 시각자료를 개별 검증했다는 의미에서는 아직 미완료**다. 다음 조사에서는 미검토 쪽을 순서대로 확인해 목록에 없는 자료를 추가하고, 목록의 캡션 추정을 실제 소주제·삽입 위치·형식·설명 목적 기록으로 교체해야 한다. 같은 지면을 다시 보더라도 확인 수준을 과장하지 않는다.

이 기억은 이후 이 프로젝트에서 문서를 작성할 때 참고하는 파일이다. 프로그램의 자동작성 코드나 인공지능 요청문에 자동 연결한 것은 아니다. 프로그램과 기존 사용자 문서는 이번 조사에서 변경하지 않는다.
