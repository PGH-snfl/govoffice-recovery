# 처음 실행하고 개발 이어가기

범정부오피스는 내부용 Windows 프로그램이다. 저장소는 비공개로 유지한다. 권한이 있는 사람이 전체 저장소를 내려받아 압축 해제하거나 Git으로 복제한다. `new_project/`만 따로 내려받으면 실행환경과 보안 모듈이 빠진다.

## 1. 필요한 환경

- Windows 64비트. 화면은 Windows PowerShell 5.1과 WPF(Windows Presentation Foundation, Windows 화면 구성 기술)를 사용한다.
- 정식 설치된 데스크톱 한컴 한글. 웹 편집기·뷰어만으로는 문서 자동화 기능을 사용할 수 없다. 포함된 보안 모듈과 설치된 한글의 비트수가 맞아야 한다.
- Python 3.13, pywin32(Python에서 Windows 자동화 기능을 사용하는 연결 라이브러리), 화면 자원과 보안 모듈은 함께 들어 있다. 기본 실행에 별도 `pip install`은 필요하지 않다.
- 인공지능 작성은 선택 기능이다. 현재 연결 코드는 설치된 Codex 실행파일과 사용자 본인의 로그인 상태를 사용한다. 계정·토큰은 저장소에 포함하지 않는다. 기존 로그인이나 사용 가능 여부를 다른 사람에게 전달하지 않는다.

## 2. 처음 실행

1. 압축파일 안에서 직접 실행하지 말고 전체를 쓰기 가능한 폴더에 푼다. 가능하면 짧은 경로(예: `C:\work\govoffice`)를 사용한다.
2. 루트의 `시작전_점검.cmd`를 실행한다. 필수 파일·Python·화면 환경·문자 인코딩·저장 가능 여부·한글 등록을 점검한다. 문서를 열거나 레지스트리를 바꾸지는 않는다.
3. 통과한 뒤 루트의 `범정부오피스_실행.cmd`를 실행한다. 기존 개발 런처는 권한 승인을 요청할 수 있다. 한글과 프로그램의 실행 권한이 다르면 연결 문제가 생길 수 있으므로 진단 내용을 먼저 확인한다.
4. 처음에는 예시 문서의 사본으로 시험한다. `materials/examples/범피스 예시1.hwp`, `범피스 예시2.hwp`가 포함돼 있다. 프로그램 상단의 불러오기로 연결한다.
5. 개인 정보·즐겨찾기는 각자 새로 입력한다. 양식은 자신의 문서로 등록하거나 포함된 서울과기대 기후부 예시 기능으로 시작한다. 자동작성 결과는 검토 초안이며 바로 제출할 수 있다는 보장이 아니다.

처음 실행 시 Windows가 내려받은 파일을 차단했다면 출처와 파일을 확인한 뒤 Windows의 파일 속성 안내를 따른다. 보안 프로그램 전체 해제나 시스템 보안 설정의 일괄 변경은 필요하지 않다.

## 3. 개발·검사

루트의 `전체검사.cmd`를 실행하면 새 임시 사용자 데이터로 자동검사를 수행한다. 개인 설정·등록 양식·기존 작성 이력은 검사 데이터로 사용하지 않는다.

PowerShell에서 실행할 경우:

```powershell
.\범피스1303_분석\python313\python.exe -B new_project\product\support\check_checkout.py --offline
.\범피스1303_분석\python313\python.exe -B new_project\development\run_tests.py
.\범피스1303_분석\python313\python.exe -B new_project\run_app.py --list --search 표 --limit 10
```

`--offline`은 한글 설치 상태 검사를 생략하고 파일·실행환경만 검사한다. `-B`는 Python 캐시 생성을 막는다. 명령줄 기능 목록 조회는 한글 문서를 편집하지 않는다. 전체 자동검사에는 화면 구성의 모의 검사도 포함되며 실제 한글 문서 왕복 검증과는 다르다.

개발 시작 위치:

- `new_project/src/govoffice/`: 실제 기능 코드
- `new_project/development/tests/`: 자동검사
- `new_project/development/tools/`: 재현·복구·검증 도구
- `new_project/development/docs/README.md`: 설계 문서 색인
- `docs/DIRECTORY_LAYOUT.md`: 전체 폴더 안내
- `AGENTS.md`: 이 프로젝트의 작업 규칙과 작성 기억 사용 규칙

## 4. 함께 저장한 것과 제외한 것

저장소에는 현재 소스·실행 자원·기본 양식·검사 코드·복구 근거·연구 레퍼런스 기록을 포함한다. 기존 원본 프로그램과 라이브러리의 권리 표시는 유지한다. 내부 협업 보관이며 이를 근거로 제3자 자산의 공개 재배포 권리가 생기는 것은 아니다.

다음은 원래 PC에 보존하지만 업로드하지 않는다.

- `new_project/config/`의 개인정보, 즐겨찾기, 프리셋, 등록 양식과 작성 이력
- `new_project/ai_response_library/`의 실제 프롬프트·응답 JSON(JavaScript Object Notation, 구조화된 텍스트 저장 형식)
- 실제 문서·실검증 결과와 화면 캡처. `materials/`는 안내와 기존 일반 예시 2개, 기본 빈 양식만 포함한다.
- 로컬 백업·임시파일·실행 로그·생성된 내부 설치 묶음

따라서 새로 내려받으면 작성자의 개인정보와 이미 작성한 연구문서가 표시되지 않는 것이 정상이다. 이전 기록에서 개인 작업 파일로 연결되는 링크는 로컬에서만 열릴 수 있다. 코드 실행에 필요한 파일은 별도로 포함했다.

## 5. 문제가 있을 때

- **Python을 찾지 못함**: 저장소 전체를 풀었는지, `범피스1303_분석/python313/python.exe`가 있는지 확인한다.
- **한글 등록·비트수 오류**: 설치된 한글과 보안 모듈의 호환을 확인한다. 실제 연결은 COM(Component Object Model, Windows 프로그램 간 제어 방식)을 사용한다.
- **한글이 깨져 보임**: `.ps1` 파일의 UTF-8 BOM(Byte Order Mark, 인코딩 식별 표시)을 유지한다. `.cmd`는 Windows 줄바꿈을 사용한다.
- **인공지능 연결 안 됨**: 기본 한글 기능과 별개다. 본인 PC의 Codex 설치·본인 계정 연결을 확인한다. 연결 코드는 필요할 때 `GOVOFFICE_CODEX_EXE`에 실행파일의 전체 경로를 받는다. 비밀번호나 토큰을 프로젝트 설정에 넣지 않는다.
- **기존 개인 문서를 못 찾음**: 의도적으로 공유에서 제외했다. 본인의 문서를 다시 선택·등록한다.

점검 통과는 모든 PC와 모든 문서의 호환 보증이 아니다. 최초 사용 PC에서는 사본 문서로 열기·기본 서식·새 파일 저장을 확인한 후 실제 업무에 적용한다.
