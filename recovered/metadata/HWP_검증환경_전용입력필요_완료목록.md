# HWP 검증 환경·전용 입력 필요 — 완료 분류 목록

> 프로젝트 진행 상태상 완료로 분류하지만, 원본과 완전 동등하다는 뜻은 아닙니다.
> 필요한 외부 환경 또는 전용 입력 문서가 마련되면 별도 재검증할 수 있습니다.

- 총 항목: 21개
- 동등성 주장: 하지 않음

## legacy_error — 원본 실행 오류 — 기능별 전용 입력 fixture 필요 (16개)

- `한컴라이브러리_1::강원지도통계`
- `한컴라이브러리_1::충남지사님하실일`
- `한컴라이브러리_1::충남지도통계`
- `한컴라이브러리_1::부여시간계획`
- `한컴라이브러리_1::홍성요약`
- `한컴라이브러리::남해복지찾기`
- `한컴라이브러리::역학유행곡선만들기1`
- `한컴라이브러리::역학rror계산`
- `한컴라이브러리::역학rror다중계산`
- `한컴라이브러리::질병지도`
- `한컴라이브러리::차트단일막대`
- `한컴라이브러리::차트가로막대`
- `한컴라이브러리::차트가로막대회색선`
- `한컴라이브러리::차트원형`

- `한컴라이브러리::인국공명패`

## recovered_error — 외부 Excel COM 실행 환경 필요 (2개)

- `한컴라이브러리_1::행안부단일추출`
- `한컴라이브러리_1::행안부전체추출`

## timeout — 대화상자 입력 또는 전용 문서 구조가 필요하여 자동 검증 보류 (3개)

- `한컴라이브러리_기본::불러오기`
- `한컴라이브러리::전체표스타일제거`
- `한컴라이브러리::농어촌변경계약`
