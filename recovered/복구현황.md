# 한글 모듈 복구 현황

기준 원본은 `범피스1303_분석/pyz_modules/한컴오피스/`의 네 marshal이다.

| 클래스 | 소스 복구 | 미복구 바이트코드 | 전체 |
|---|---:|---:|---:|
| 한컴기본 | 310 | 0 | 310 |
| 한컴1 | 293 | 0 | 293 |
| 한컴2 | 98 | 0 | 98 |
| 기본한컴 | 810 | 0 | 810 |
| 합계 | 1,511 | 0 | 1,511 |

복구 완료 코드는 `한컴오피스/recovered_source/`에 기능별로 분리했다.
`한컴오피스/compat/`는 원본 비교용 보존 자료이며 현재 진입점에서는
가져오거나 실행하지 않는다. 최신 권위 상태는 `metadata/hwp_coverage.json`이다.
