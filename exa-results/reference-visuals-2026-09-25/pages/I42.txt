초록
▼
□ 연구개요
본 연구는 SW 오류를 자동으로 발견하는 체계적이고 과학적인 기술 개발을 통한 SW품질향상을 목표로 한다. 효과적인 자동 테스팅 및 자동 디버깅 기술을 개발하기 위해, 본 연구는 동적심볼릭 실행 기술 (dynamic symbolic execution)과 SW변형기술 (software mutation analysis)을 활용하여 다음의 3가지 세부연구 주제를 다룬다.
● SW유닛 테스트 환경 자동 생성 기술: 다양하고 실제적이며 간결한 SW유닛 테스팅 환경을 자동으로 생성한 후, 동적 심볼릭 실행을 적용
□ 연구개요
본 연구는 SW 오류를 자동으로 발견하는 체계적이고 과학적인 기술 개발을 통한 SW품질향상을 목표로 한다. 효과적인 자동 테스팅 및 자동 디버깅 기술을 개발하기 위해, 본 연구는 동적심볼릭 실행 기술 (dynamic symbolic execution)과 SW변형기술 (software mutation analysis)을 활용하여 다음의 3가지 세부연구 주제를 다룬다.
● SW유닛 테스트 환경 자동 생성 기술: 다양하고 실제적이며 간결한 SW유닛 테스팅 환경을 자동으로 생성한 후, 동적 심볼릭 실행을 적용하여 SW유닛 테스팅을 100% 자동화하는 기술
● SW변형 기반 자동 테스트 기술: SW유닛 테스팅 환경의 제약점 극복을 위해, 대상 SW유닛 자체를 변형하여 효과적인 테스트를 자동으로 생성하는 기술
● SW 디버깅 정보 자동 생성 기술: 수많은 테스트 케이스를 분석하여, 버그 위치를 자동으로 탐색하고 버그 수정에 필요한 정보를 자동으로 생성하는 기술
□ 연구 목표대비 연구결과
본 연구에서는 대상SW의 다양한 동작을 관찰하기 위해 동적 심볼릭 실행 기법(dynamic symbolic execution)과 SW변형기법 (mutation analysis)을 기반으로 SW유닛 테스팅 환경을 자동으로 생성하고, SW오류 검출 및 디버깅을 자동으로 수행하는 연구를 진행하여 다음 연구 결과를 얻을 수 있었다.
● SW유닛 테스트 환경 자동 생성 기술:
- 동적 분석을 활용한 조건부 확률 기반 함수간 연관도 측정 메트릭 기술 개발
- 유닛 테스트 정확도 향상을 위한 함수 연관도에 기반한 심볼릭 함수 호출 문맥 기술 개발
- 세계 최고 수준의 오류 검출 능력 (91% 오류 검출) 및 정확도 (거짓:참 경보 비율 4.5:1) 달성
● SW변형 기반 자동 테스트 기술:
- 오픈소스 C 프로그램 변형 분석 도구 MUSIC 개발 (https://github.com/swtv-kaist/MUSIC)
- 변형 프로그램으로부터 커버리지 향상을 위한 가이드포스트 생성 및 SW 테스트 자동 생성 기술 개발
- 오픈소스 C 프로그램 대상 커버리지 평균 14.1%p 향상
● SW 디버깅 정보 자동 생성 기술:
- SW 변형 분석과 관찰 기반 분석을 결합한 정확도 높은 버그 위치 탐색 기술 개발
- 기계학습 기반 SW 디버깅 정보 생성 기술 개발
- 세계 최고 수준의 버그 위치 탐색 정확도 (평균 5.9% 구문 분석) 달성
□ 연구개발결과의 중요성
본 연구는 SW 테스팅 및 디버깅 전반의 자동화와 고도화를 통해 SW품질 향상, SW테스팅 소요인력 절감, SW테스팅 기간단축으로 인한 제품개발 기간단축 등을 통하여 제품 품질 및 개발 효율을 향상시킬 수 있다. 본 연구 결과는 기존에 달성하지 못한 세계 최고 수준의 오류 탐지 능력과 정확도를 달성하였을 뿐 아니라, 실제 개발 환경에 적용하여 SW 테스팅 비용을 줄이고 품질 향상에 기여하였음을 보였다. 특히, 현대모비스와의 산학협력을 통해 본 연구 결과가 차량 SW 테스팅 시간을 50~70% 단축시킬 수 있음을 실증적으로 입증하여 현대모비스의 차량 SW 테스트 프로세스에 본 연구 결과가 전사적으로 도입되는 성과를 달성하였다.
학문적/연구적 측면에서는, 기존 SW테스팅 자동화 연구 범위를 테스트케이스 생성 수준에서 테스팅 환경 분석 및 자동 생성, 디버깅 자동화 분야까지 확장한 세계적으로 선도적인 연구이므로, 후속 관련 연구들이 활성화될 것을 기대한다. 특히, SW변형 기반 테스트 생성 기법의 경우, 기존 테스팅의 한계를 극복하는 세계 첫 번째의 독창적인 시도인 만큼, SW 변형 기법을 새로운 관점/용도로 활용하는 다양한 후속 연구들이 파생되어 새로운 연구주제들이 도출되리라 기대한다.
