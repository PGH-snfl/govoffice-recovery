연구개요
본 연구는 SW 오류를 자동으로 발견하는 체계적이고 과학적인 기술 개발을 통한 SW품질향상
을 목표로 한다. 효과적인 자동 테스팅 및 자동 디버깅 기술을 개발하기 위해, 본 연구는 동적 
심볼릭 실행 기술 (dynamic symbolic execution)과 SW변형기술 (software mutation analysis)
을 활용하여 다음의 3가지 세부연구 주제를 다룬다. ● SW유닛 테스트 환경 자동 생성 기술: 다양하고 실제적이며 간결한 SW유닛 테스팅 환경을 
자동으로 생성한 후, 동적 심볼릭 실행을 적용하여 SW유닛 테스팅을 100% 자동화하는 기술
● SW변형 기반 자동 테스트 기술: SW유닛 테스팅 환경의 제약점 극복을 위해, 대상 SW유닛 
자체를 변형하여 효과적인 테스트를 자동으로 생성하는 기술
● SW 디버깅 정보 자동 생성 기술: 수많은 테스트 케이스를 분석하여, 버그 위치를 자동으로 
탐색하고 버그 수정에 필요한 정보를 자동으로 생성하는 기술
연구 목표대비 
연구결과
본 연구에서는 대상SW의 다양한 동작을 관찰하기 위해 동적 심볼릭 실행 기법(dynamic 
symbolic execution)과 SW변형기법 (mutation analysis)을 기반으로 SW유닛 테스팅 환경을 자
동으로 생성하고, SW오류 검출 및 디버깅을 자동으로 수행하는 연구를 진행하여 다음 연구 
결과를 얻을 수 있었다. ● SW유닛 테스트 환경 자동 생성 기술: 
 - 동적 분석을 활용한 조건부 확률 기반 함수간 연관도 측정 메트릭 기술 개발
 - 유닛 테스트 정확도 향상을 위한 함수 연관도에 기반한 심볼릭 함수 호출 문맥 기술 개발
 - 세계 최고 수준의 오류 검출 능력 (91% 오류 검출) 및 정확도 (거짓:참 경보 비율 4.5:1) 
달성
● SW변형 기반 자동 테스트 기술: 
 - 오픈소스 C 프로그램 변형 분석 도구 MUSIC 개발 (https://github.com/swtv-kaist/MUSIC) - 변형 프로그램으로부터 커버리지 향상을 위한 가이드포스트 생성 및 SW 테스트 자동 생
성 기술 개발
 - 오픈소스 C 프로그램 대상 커버리지 평균 14.1%p 향상
● SW 디버깅 정보 자동 생성 기술: 
 - SW 변형 분석과 관찰 기반 분석을 결합한 정확도 높은 버그 위치 탐색 기술 개발
 - 기계학습 기반 SW 디버깅 정보 생성 기술 개발
 - 세계 최고 수준의 버그 위치 탐색 정확도 (평균 5.9% 구문 분석) 달성
연구개발결과의 
중요성
본 연구는 SW 테스팅 및 디버깅 전반의 자동화와 고도화를 통해 SW품질 향상, SW테스팅 소
요인력 절감, SW테스팅 기간단축으로 인한 제품개발 기간단축 등을 통하여 제품 품질 및 개
발 효율을 향상시킬 수 있다. 본 연구 결과는 기존에 달성하지 못한 세계 최고 수준의 오류 
탐지 능력과 정확도를 달성하였을 뿐 아니라, 실제 개발 환경에 적용하여 SW 테스팅 비용을 
줄이고 품질 향상에 기여하였음을 보였다. 특히, 현대모비스와의 산학협력을 통해 본 연구 결
과가 차량 SW 테스팅 시간을 50~70% 단축시킬 수 있음을 실증적으로 입증하여 현대모비스
의 차량 SW 테스트 프로세스에 본 연구 결과가 전사적으로 도입되는 성과를 달성하였다. 학문적/연구적 측면에서는, 기존 SW테스팅 자동화 연구 범위를 테스트케이스 생성 수준에서 
테스팅 환경 분석 및 자동 생성, 디버깅 자동화 분야까지 확장한 세계적으로 선도적인 연구이
므로, 후속 관련 연구들이 활성화될 것을 기대한다. 특히, SW변형 기반 테스트 생성 기법의 
경우, 기존 테스팅의 한계를 극복하는 세계 첫 번째의 독창적인 시도인 만큼, SW 변형 기법을 
새로운 관점/용도로 활용하는 다양한 후속 연구들이 파생되어 새로운 연구주제들이 도출되리
라 기대한다. 중심어

1. 연구개발과제의 개요
그림 1. 제안한 연구를 통한 SW 테스팅/디버깅 프로세스 개선
l SW유닛 테스트 환경 자동 생성 기술: 다양하고 실제적이며 간결한 SW유닛 테스팅 환경을 자동으로 
생성한 후, 동적 심볼릭 실행을 적용하여 SW유닛 테스팅을 100% 자동화하는 기술
테스트 드라이버, 스텁 (stub), 테스트 케이스 등 SW유닛 환경은 SW 유닛 테스트에 큰 영향을 끼치
는 만큼, 다양하고 실제적인 SW 유닛 환경을 생성하는 기술을 연구한다. 이를 위해 대상 SW유닛과 
연관성이 높은 다른 SW유닛의 코드를 포함하여 동적 심볼릭 실행을 수행하여, 대상 SW유닛에 다양
하고 실제적인 환경(context)를 제공하여 대상 SW유닛의 다양하고 실제적인 동작을 테스트한다. l SW변형 기반 자동 테스트 기술: SW유닛 테스팅 환경의 제약점 극복을 위해, 대상 SW유닛 자체를 
변형하여 효과적인 테스트를 자동으로 생성하는 기술
SW유닛 테스팅 환경의 제약점을 극복하는 또 다른 방법으로, 대상 SW유닛 자체를 변형한 후 테스트
한 동작들 중 원본 SW유닛에서 오류를 일으킬 수 있는 동작들을 선별한다. 그리고 그러한 동작들로
부터 얻은 정보를 바탕으로 원본 SW에서 발생 가능한 오류 시나리오를 생성한 후, 오류 시나리오를 
재현 할 수 있는 테스팅 환경을 자동으로 생성한다. l SW 디버깅 정보 자동 생성 기술: 수많은 테스트 케이스를 분석하여, 버그 위치를 자동으로 탐색하고 
버그 수정에 필요한 정보를 자동으로 생성하는 기술 
대상SW의 구문을 하나씩 변형시킨 변형SW들의 테스트케이스의 결과와 원본SW의 테스트케이스 결
과의 차이를 바탕으로 버그 위치를 정확하게 찾아내고, 버그 위치에 변형이 생성된 변형SW들의 동
작을 관찰하여 버그 수정에 필요한 정보를 추출하여 디버깅에 사용한다. 또한 수많은 변형 SW들이 
생성되어 이들을 테스트하는 시간이 크므로, 디버깅 자동화에 대한 효과 및 효율이 높은 변형연산자 
및 테스트케이스를 선별하여 적용한다.
국가연구개발 보고서원문 성과물 전담기관인 한국과학기술정보연구원에서 가공·서비스 하는 연구보고서는 동의 없이 상업적 및 기타 영리목적으로 사용할 수 없습니다.

2. 연구수행내용 및 연구결과
(1) SW유닛 테스트 환경 자동 생성 기술
다양하고 실제적인 유닛 테스팅 환경 자동 생성
Ÿ 동적 분석을 활용한 조건부 확률 기반 함수간 연관도 (relevance) 측정 메트릭 개발 
 - 알고리즘 1의 Step 1과 Step 2 참고
Ÿ 연관도 높은 함수들을 포함하는 확장 유닛 테스트 환경 자동 생성 기술 개발
 - 알고리즘 1의 Step 3 참고
Ÿ 오픈소스 C 프로그램 대상으로, 연관도 측정 메트릭을 활용한 확장 유닛 테스트가, 오류를 많이 검출하면서 
거짓 경보를 줄임을 실험적으로 보임
 - “나) 연구 기술 적용 실험 결과” 참고
Ÿ 연구결과를 응용하여 현대모비스와 차량용SW 테스팅 도구 MAIST를 공동 개발하여 테스팅 비용 
50% 이상 감소
 - 대표적 연구실적 4번, 5번 및 “나) 연구 기술 적용 실험 결과” 마지막 문단 참고
효과적인 오류 검출을 위한 새로운 동적 심볼릭 실행 탐색 기법
Ÿ 테스트 대상 유닛 함수의 분기문에 높은 우선순위를 부여하는 효과적인 동적 심볼릭 실행 탐색 기
법 개발
 - 알고리즘 1의 Step 4 참고
Ÿ 오픈 소스 C 프로그램을 대상으로, 높은 오류 검출 능력 및 낮은 거짓 경보 비율 입증

Step 3에서 생성한 확장 유닛을 사용하여 Concolic 테스트를, 테스트 대상 유닛 함수의 분기문에 높은

(symbolic execution path)를 기록한다. ◯ Step 5: 거짓 경보 필터링
Step 4에서 발생한 단언문 위반 경보 중에서 symbolic calling context의 조건을 만족하지 않는 경보
를 제거하고 제거되지 않은 경보를 사용자에게 보고한다. 알고리즘 1. SW 유닛 테스트 환경 자동 생성 기술

관찰 분석을 결합한 SW 디버깅 정보 자동 생성 기술은, 아래 알고리즘 3의 세 단계로 수행된다. ◯ Step 1: 원본 프로그램의 분석 대상 구문 선택 
입력으로 주어진 테스트 집합 T를 분석 대상 프로그램 P에 실행하여 분석 대상 구문을 확인한다. 분
석 대상 구문은 버그 구문, 즉 테스트를 실패하게 만들 수 있는 가능성이 있는 구문이다. 따라서 최소 
한 개 이상의 실패한 테스트가 실행한 구문이 분석 대상 구문이며 실패한 테스트가 전혀 실행하지 않
은 구문은 우리가 찾고자 하는 버그 구문과는 무관하기 때문에 분석 대상 구문에서 제외한다. ◯ Step 2: 변형 프로그램 생성 및 테스트 수행
Step 1에서 찾은 분석 대상 구문에, MBFL의 정확도는 높이고 실행시간은 줄이는 변형 연산자를 적용
하여 변형 프로그램을 생성하고 생성한 변형 프로그램에, 역시 MBFL의 정확도를 높이며 실행시간을 
줄이는 테스트 집합 T를 실행하여 변형 프로그램 테스트를 수행한다. 이 때 분석 대상 프로그램 P에
서는 성공했으나 변형 프로그램에서는 실패한 테스트(가설/관찰 1)와 분석 대상 프로그램 P에서는 실
패했으나 변형 프로그램에서는 성공한 테스트(가설/관찰 2)의 정보를 추출한다. ◯ Step 3: 변형 프로그램 테스트 결과 및 관찰 분석 결과를 활용하여 버그 의심도 순위 계산
Step 2에서 수행한 변형 프로그램 테스트 결과와 관찰 분석 결과를 활용하여 버그 의심도 순위를 계
산한다. 버그 의심도는 각 분석 대상 구문이 실제 오류인지 아닌지를 나타내는 정량 지표이다. 버그 의심도의 
상대적인 대소 비교를 통해 분석 대상 구문이 실제 오류일지 아닐지를 보여주는 의심도 순위를 메긴
다. RankSVM 과 같은 기계학습 기반의 알고리즘 특성상 기계학습으로 계산한 버그 의심도의 절대적
인 값의 차이는 크게 중요하지 않으며 버그 구문의 의심도 순위를 계산하기 위한 상대적인 대소 관계
가 중요하다. 버그 의심도를 구체적으로 계산하기 위해서 SW 변형 분석 결과 7개와 SW 관찰 분석 
결과 3개의 특징(feature)을 사용한 기계학습/추론을 수행하였다. 기계학습 방법으로는 순위를 계산하
는데 효과적이라고 알려진 RankSVM 기법을 활용하였다. 알고리즘 3. SW 번형 분석 및 관찰 분석을 결합한 SW 디버깅 정보 자동 생성 기술
나) 연구 기술 적용 실험 결과 (세부 목표 증빙 1번 참고)
개발한 SW 디버깅 정보 자동 생성 기술이 실제 효과적으로 버그 구문의 위치를 추정할 수 있는지 확인

효과적인 SW 테스팅 및 디버깅 연구는 SW 공학의 기반 기술로서 SW 품질 향상 다방면에 활용될 수 
있다. 본 연구는 SW 품질 향상을 위해 표준적으로 사용되는 SW 테스팅 및 디버깅 과정을 자동화함으
로써, 테스팅 및 디버깅의 병목이었던 개발자의 시간 부족 문제를 해결하고, 수만~수십만LOC 규모의 
현실적인 SW에 적용 가능한 수준으로 개발하여 관련 연구자 뿐 아니라 SW 개발 현장의 개발자 및 테
스트 전문가가 활용할 수 있는 수준의 기술을 개발하였다. (1) 학문적 활용 
l 유닛 테스팅 분야에 새로운 연구 문제(research problem) 제시
기존 SW 테스팅 자동화 연구는 테스트 입력 값 자동 생성에 집중하고 있으나, 본 연구는 테스트 입
력 값 뿐 아니라 테스트 드라이버/스텁 함수 생성 자동화를 포함하여 기존 SW 테스팅 자동화 기법
보다 버그 잡는 효과 및 테스트 커버리지를 효과적으로 높일 수 있었다. l 동적 심볼릭 테스팅 분야에 테스팅 정확도를 향상하는 새로운 방안 제시
본 연구는 테스트 대상 유닛의 실제 실행 시나리오를 고려하여 SW 유닛 환경을 자동으로 생성함으
로써 실제 실행 시나리오를 고려하지 않은 기존의 SW 유닛 환경 자동 생성 기법보다 더 정확한(거
짓 경보 비율이 더 적은) 테스트 결과를 산출하였다. l SW변형 기술의 새로운 응용분야 제시
테스트 품질 평가와 회귀 테스트에 제한적으로 사용되던 SW 변형 기법을 사용하여 SW유닛 변형 테
스트를 생성함으로써, SW 테스팅의 효과성을 높이고 SW 변형 기법 활용의 새 지평을 열었다. (2) 기술적/산업적 활용 
l SW 품질, 생산성, 경쟁력 강화
본 연구는 SW 테스팅 및 디버깅 과정을 자동화함으로써 SW 개발 비용 중 가장 많은 비율을 차지하
는 SW 품질관리 및 유지보수에 비용을 줄이고 SW 융복합산업의 경쟁력을 강화시켰다. 특히, 현대
모비스와의 산학협력을 통해, 본 연구 결과를 적용했을 때 차량제어 SW의 테스팅 비용이 50~70% 
절감됨을 실증적으로 입증하였다. l 실제 SW 산업의 필요에 부응하는 연구 개발
본 연구는 SW 코드를 분석하여 SW품질을 향상시키는 연구이므로, SW융복합 산업계가 당면하고 있
는 SW 품질 문제에 해결책이 된다. l 오픈소스 SW도구 개발을 통한 연구 결과 파급
본 연구의 성과로 개발한 SW도구를 오픈소스 프로젝트 형태로 공개하여 다양한 산업체, 연구소에서 
활용 가능하도록 함으로써, 연구 결과를 사회 전반에 효과적으로 보급되도록 지원하였다.

inputs. However, automatically generated unit test drivers/stubs raise false alarms because they often 
over-approximate real contexts of a target function f and allow infeasible executions of f. To solve this 
problem, we have developed a concolic unit testing technique CONBRIO. To provide realistic context to 
f, it constructs an extended unit of f that consists of f and closely relevant functions to f. Also, 
CONBRIO filters out a false alarm by checking feasibility of a corresponding symbolic execution path 
with regard to f's symbolic calling contexts obtained by combining symbolic execution paths of f's 
closely related predecessor functions.
In the experiments on the crash bugs of 15 real-world C programs, CONBRIO shows both high bug 
detection ability (i.e. 91.0% of the target bugs detected) and high precision (i.e. a true to false alarm 
ratio is 1:4.5). Also, CONBRIO detects 14 new bugs in 9 target C programs studied in papers on crash 
bug detection techniques.

techniques still test a target program as it is, and fail to utilize valuable information of diverse test 
executions on many variants of the original program in test generation. This paper proposes a new 
direction for software testing - Invasive Software Testing (IST). IST first generates a set of target 
program variants m1, ⋯, mn from an original target program p by applying mutation operations μ1, ⋯, μn . Second, given a test suite T, IST executes m1, ⋯, mn with T and records the test runs which

guideposts for automated test generation on p toward high test coverage. Finally, IST generates test 
inputs on p with the guideposts and achieves higher test coverage. We developed DEMINER which 
implements IST for C programs through software mutation and concolic testing. Further, we showed the 
effectiveness of DEMINER on three real-world target programs Busybox-ls, Busybox-printf, and 
GNU-find. The experiment results show that the amount of the improved branch coverage by DEMINER 
is 24.7% relatively larger than those of the conventional concolic testing techniques on average.

conventional mutation operators, observes the dynamic behavioral changes in a test suite, and reports 
suspicious statements. To reduce the analysis cost, MUSEUM selects a subset of mutated programs 
and test cases.

as the most suspicious statements for both resolved and unresolved non-trivial bugs in real-world 
multilingual programming projects; and (ii) efficient: it locates the buggy statements in modest amount 
of time using multiple machines in parallel. Also, by applying selective mutation analysis (i.e., selecting 
subsets of mutants and test cases to use), MUSEUM achieves significant speedup with marginal 
accuracy loss compared to the full mutation analysis.

shows that mutation analysis can provide an effective, efficient, and language semantics agnostic 
analysis on multilingual code. Our light-weight analysis approach would play important roles as 
programmers write and debug large and complex programs in diverse programming languages.

Although mutation analysis is important for various software analysis tasks, there exist few practical 
mutation tools for C programs. We have developed MUSIC (MUtation analySIs tool with high 
Configurability and extensibility) which generates mutants for modern complex real-world C programs. 
MUSIC provides various mutation operators including 10 new mutation operators such as string and 
function call mutation operators as well as 63 conventional mutation operators. Also, MUSIC supports 
a user to create a new mutation operator easily. Furthermore, MUSIC can select a domain and a 
range of a mutation operator for various purposes. 
We have applied Milu, Proteum, and MUSIC to Siemens benchmark programs and a modern 
real-world C program cURL, and compared them in terms of applicability and a number of stillborn 
(i.e., syntactically illegal) mutants generated. In the experiment, MUSIC successfully generates mutants 
without any stillborn mutants.

인공지능 소프트웨어 검증시스템 ‘마이스트(MAIST)’… 업무효율 2배 향상
 현대모비스와 공동으로 개발한 마이스트는 개발자 대신 체계적이고 자동화된 방법으로 소프트
웨어 검증작업을 수행하는 시스템이다. 마이스트는 연구원들이 설계한 알고리즘을 바탕으로 소프
트웨어의 모든 가능한 동작을 체계적으로 검증한다. 기존 수작업으로 이뤄지던 소프트웨어 검증 
업무를 자동화한 것이다. 현대모비스는 마이스트를 통합형 차체제어시스템(IBU)과 써라운드뷰모니터링 시스템(SVM) 검
증에 시범 적용한 결과, IBU와 SVM의 소프트웨어 검증 업무의 각 53%, 70%를 마이스트가 처
리했다고 밝혔다. 현대모비스 플랫폼 소프트웨어 개발실장 이승용 이사는 “마이스트가 검증 업무의 50~70%를 
대신하면서 연구원들은 더 창의적인 환경에서 알고리즘 설계 역량을 강화하고 급속도로 증가하는 
차량용 소프트웨어 개발에 신속 정확하게 대응할 수 있게 됐다”고 말했다. 현대모비스는 2018년 하반기부터 마이스트를 소프트웨어가 탑재되는 전장 전 부품으로 확대 
적용한다. 제동과 조향 등의 핵심부품은 물론 자율주행·첨단 운전자 지원시스템(ADAS)·친환경 
등 미래차 연구 전 부문으로 확대한다. 글로벌 소프트웨어 연구기지인 인도연구소에도 적용할 방
