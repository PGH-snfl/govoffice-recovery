－ ONF는 T-SDN 표준 기술과 관련된 여러 표준화 기구(ITU-T, OIF, MEF, TMF)들과 
협업을 통해서 ONF가 주도적으로 추진하고 있는 UML 기반의 정보 모델 채택을

반면에 사실상 IP(L3 레이어) 기반의 L2/L3 프로토콜을 주도하고 있는 IETF는 
ONF와의 협업에 소극적임
❍ (표준화 추진 현황) 현재 개발된 대부분의 T-SDN 컨트롤러 기술은 기존의 전용서비스를 
수용하기 위한 제한된 SDN 서비스를 제공하고 있으며, 표준화 기구(ONF, IETF)를 
중심으로 표준화된 컨트롤러 인터페이스와 확장된 네트워크 서비스를 지원할 수 있도록 
T-SDN 컨트롤러 구조 및 모델링에 대한 기본적인 T-SDN 서비스에 대한 표준화가 
추진되고 있음 
－ T-SDN 표준화는 use case를 기반으로 요구 사항을 도출한 다음 정보 
모델링(information modeling)을 통해서 T-SDN 컨트롤러의 NBI/SBI 인터페이스를 
추출하는 단계적 방식의 표준화가 추진 중이며, OAM을 포함한 다양한 
요구사항들이 추가되어 기존의 Operation Support System(OSS) 기능이 통합되는 
구조로 발전되고 있음

RESTful API는 HTTP를 사용하기 때문에 테스트 하기가 단순하며 반복적이다. 컨트롤러가 
제공하는 API Endpoint의 수가 적고, 향후 증가될 가능성이 적은 경우 직접 쉘 스크립트를 
작성하거나 특정 프로그래밍 언어를 사용해 테스트를 진행할 수 있다. 그러나 Endpoint의 수가 
많아지거나, 향후 증가될 가능성이 큰 경우 반복되는 작업을 단순화 및 최소화 하기 위한 
노력이 필요하다. RESTful API 테스트를 쉽게 하기 위해 테스트 자동화 프레임워크를 
만들었고, RESTful API를 테스트 하는 코드는 모듈화해 AAT Plugin 형태로 개발하였다
[그림 5] Maven과 T-SDN 간 Unit-Test 구조도 
가. T-SDN 컨트롤러 시험 소프트웨어 기술 개발
❍ 컨트롤러는 REST 프레임워크를 사용하여 검증할 수 있다. ❍ AAT REST Plugin은 사용자가 작성한 스크립트에 따라 다양한 HTTP Client 기능과

사용자가 예상한 모델과 일치하는지 확인한다. ❍ 구체적으로 REST Plugin은 YAML 형식을 사용해 다음과 같은 조건을 설정 및 제약할

파일이 생성된다. 프로젝트에서 필요로 하는 의존성 정보를 pom.xml 에 표기하면 된다.

3. 표준 기반 가상 네트워크 서비스 기술
가상 네트워크 서비스는 사용자에게 실시간으로 네트워크을 제공할 수 있도록 IETF에 
표준을 제안하고 표준 규격에 준하여 사용자와 통신사업자 (T-SDN 컨트롤러) 사이의 상세 
규격과 동작을 설계하였다. 가. 가상 네트워크 서비스 설계 
❍ IETF에서 규정하는 가상 네트워크 서비스(VN: Virtual Network)를 제공하기 위해서 
사용자 컨트롤러(CNC: Customer Network Controller)와 통신사업자 컨트롤러 (MDSC: 
Multi-domain Service Coordinator) 사이는 IETF YANG 데이터 모델을 사용한다. － A Yang Data Model for ACTN VN Operation (draft-lee-teas-actn-vn-yang).
❍ 가상 네트워크 서비스는 두 개의 종류로 구분 한다: (1) 터널 기반으로 네트워크 END 
지점만을 연결하는 방식과 (2) 가상 링크와 노드로 구성되는 토폴로지 방식
❍ 다음 그림처럼 사용자(CNC)가 Yang 모델 기반의 Restconf 프로토콜을 사용하여 
source, destination, bandwidth, latency, Policy 등의 패러미터와 함께 T-SDN 
컨트롤러에게 가상네트워크 서비스 설정을 요청하면, T-SDN 컨트롤러는 가상 
네트워크서비스 설정을 완료한 다음 사용자에게 회신(Notification)한다. ❍ 본 설계서에는 가상 네트워크 Yang 데이터 모델, 가상 네트워크 서비스 종류, SDN 
컨트롤러 구조 및 인터페이스, 가상 네트워크 서비스 상세 처리 절차(설정, 업데이트, 삭제)를 포함한다.
