1. 연구개발과제의 개요
▣ 엣지 컴퓨팅(Edge Computing) ?
‘엣지 컴퓨팅‘은 다양한 단말 기기에서 발생하는 데이터를 클라우드와 같은 중앙 집중
식 데이터 센터로 보내지 않고 데이터가 발생한 현장 혹은 근거리에서 실시간 처리하
는 방식을 의미함. 즉 사용자의 디바이스 근처, 네트워크의 가장자리에서 컴퓨팅을 지
원하는 것으로 ‘클라우드 엣지’ 즉, 클라우드 컴퓨팅과 서비스를 네트워크의 말단부로 
확장한 것.
[ Cloud Computing vs. Edge Computing ]
엣지 컴퓨팅은 아래와 같은 특징을 가집니다.
◦ 네트워크 의존도를 낮추고 안정적으로 데이터 송수신 가능
- 데이터가 기기에 직접적으로 연결되어 있거나 기기에서 자체적으로 접속
- 가능한 네트워크 노드 상에 위치하고 있기 때문에 네트워크 지연이나 전송 오류
로부터 자유로움
- 데이터 해킹과 같은 공격으로부터의 노출을 줄일 수 있음
◦ 클라우드 컴퓨팅보다 빠른 연산과 응답이 가능
- 기기와 데이터의 물리적 거리가 짧고 연산을 위해 다루는 데이터의 양도 클라우
드 컴퓨팅에 비해 적기 때문에 상대적으로 더 빠른 연산과 데이터 전송 이 가
능(클라우드 컴퓨팅 방식에 비해 10배 빠른 속도 - IEEE 발표 자료에 언급)
◦ 기기에서 발생되는 데이터 대부분은 자체적으로 처리
- 기기에서 수집되는 막대한 데이터 대부분은 엣지 컴퓨팅으로 처리하고 중앙 데
이터 센터에는 꼭 필요한 데이터만 전송
- 이를 통해 데이터 부하를 줄이고 전송 단계에서의 보안 위협도 피할 수 있음
◦ 즉 엣지 컴퓨팅을 통해 기존 클라우드 컴퓨팅이 가졌던 한계를 극복 또는 보완
- 4차 산업혁명 시대를 대표했던 네트워크 플랫폼인 클라우드는 엣지 컴퓨팅을 
국가연구개발 보고서원문 성과물 전담기관인 한국과학기술정보연구원에서 가공·서비스 하는 연구보고서는 동의 없이 상업적 및 기타 영리목적으로 사용할 수 없습니다.

는 것이 최근 전문가들의 의견. 게다가 5G의 확대로 빠른 데이터 처리가 중요한 시대
임을 감안할 때도 클라우드의 과부하는 우려스러운 것이 사실. 이젠 물리적 통신 인프
라가 막강한 데이터 트래픽 성장을 따라가기가 사실상 불가능한 상황에 놓임에 따라 
엣지 컴퓨팅이 클라우드 컴퓨팅 과부하 해결 방안으로 등장하게 됨. - IoT 기기가 다양해지고 전송하는 데이터양이 방대해 지면서 시간·장소에 구애 
받지 않고 대한 데이터를 인터넷 상에서 공유·전송할 수 있는 컴퓨팅 기술이 발
전을 거듭
※ 세계 IoT 기기 수는 '16년 약 36억 대에서 '21년 250억 대로 32.0%의 CAGR 
 을 기록할 전망(Gartner, '17.12)
※ 세계 데이터 시장 규모는 '16년 16.1ZB(제타바이트: 1021)에서 '25년 163ZB

자원을 클라우드 공간에 임대하여 사용하고 비용을 지불하는 클라우드 컴퓨팅 
방식이 등장
- 클라우드 컴퓨팅 시장은 ICT 시장뿐 아니라 자동차·금융·의료 등 다양한 산업 
분야에 확대 적용되며 꾸준히 성장
- 하지만 산업용 IoT·자율주행자동차 등 실시간 데이터 처리가 중요한 분야는 원
격지에 있는 클라우드 컴퓨팅에서 데이터를 분석·처리하기는 효율성이 다소 떨
어진다는 평가
- 즉, 디바이스 가까운 가장자리에서 컴퓨팅 시스템을 구동하며 보다 빠르고 안정
적으로 데이터를 처리할 수 있는 컴퓨팅 기술에 대한 요구가 증대
- 추가적으로, 여러 대기업의 개인정보 유출 사례에서 알 수 있듯이 클라우드 컴
퓨팅의 통신 과정에서 발생하는 보안 문제점도 대두
- 이에 따라 디바이스와 가까운 네트워크 ‘가장자리(Edge)’에서 컴퓨팅을 지원하
는 ‘엣지 컴퓨팅(Edge Computing)’이 클라우드 컴퓨팅 한계를 보완할 수 있는 
기술로 부상
