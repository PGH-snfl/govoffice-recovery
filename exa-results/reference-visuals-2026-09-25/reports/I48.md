## 실제 지면에서 확인한 배치·형식·설명 목적

PDF 8쪽 개요는 여러 시점의 영상과 시청자→서버의 처리관계를 결합해 기존 콘텐츠 한계와 새 서비스 개념을 설명한다. 14쪽은 세부기술 간 데이터 흐름과 기관·연구팀별 담당 체계를 상하로 구분한다. 15쪽은 2단계/5개년 계획을 계단식으로 표현해 알고리즘→구현·고도화→실증·사업화 전개를 보여준다. 19쪽 시연 영상 화면은 결과 증빙이다. 25쪽은 가상시점 생성의 기하 원리와 처리장치별 구현 흐름을 상하로, 58쪽은 시점 이동·중첩영역 모식도와 실제 연결된 파노라마를 나란한 설명 흐름에 둔다. 연구팀 역할·연차·기술방법·실제 결과를 서로 다른 도식으로 분리한 서울과기대 사례다.

### 2026-09-26 추가 지면 확인

PDF 19, 20, 25, 29, 36, 48, 54, 55, 71, 77, 78, 87쪽: 19쪽 시연 플레이어 화면 2개는 작동 증빙이다. 20쪽 공연 사진/시점 배치도 아래 콘텐츠 생성·전송 시스템을 분리해 목적과 구성 관계를 설명한다. 25쪽 삼각망 변환 모식도 아래 처리장치별 흐름도를 둔다. 29쪽 프레임의 움직임 유무와 가중치 변화가 시간축에 대응한다. 36쪽 음원 위치 추정망과 환경별 정확도 표로 방법/결과를 연결한다. 48쪽 영상합성·추적의 처리 흐름과 실제 화면을 위아래/좌우로 대응한다. 54쪽 시점 변환 영상과 입력 시점 선택 기하도를, 55쪽 카메라 중첩영역 도식을 배치한다. 71쪽 실제/가상 시점 배치도와 좌우 재생 화면으로 입체영상 구현을 설명한다. 77쪽 영상의 관심영역 사각형과 시점예측망을, 78쪽 관심영역→우선순위→사전 적재 절차를 보여준다. 87쪽은 실제 관제·검출 화면 단독 예시다. 공연/예제 영상과 자체 시연·측정 증빙을 구별해야 한다.

PDF 18쪽: 무대와 실제/가상 시청 지점의 평면배치도를 두 방식으로 제시하고 이동 가능한 경로에 화살표를 붙인다. 문단에서 시청자 조작과 시점 간격을 설명하여 시연 조건을 구체화한다.
