# 서울과학기술대학교 · 기후부 2026 연구개발계획서

## 사용

범정부오피스의 **교직 → 서울과학기술대학교 → 기후부 연구계획서 자동작성 (예시)** 버튼.

한 번 누르면 별도 한글 사본에서 예시 계획서를 만들고 결과 문서와 폴더를 연다. 현재 작업 중인 한글 문서와 원본은 수정하지 않는다. 반복 실행은 새 폴더를 사용한다.

개발 환경 결과 위치: `new_project/config/generated_documents/seoultech/기후부_2026_예시_날짜_고유번호/`

## 함께 생성하는 자료

- `연구개발계획서_예시.hwp`: 실제 한글에서 저장·읽기 검증하는 주 결과물.
- `작성요령.md`: 작성요령 표 23개, 앞부분 제출 안내, 표 밖 주석과 나머지 문맥까지 보존.
- `전체원문_대조본.md`: 원본 3,074개 비어 있지 않은 문단을 원래 순서로 보관.
- `제출전_점검표.md`: 미확정 정보와 별도 발급·동의·서명이 필요한 서류.
- `입력필드_예시값.json`: 원본 문단 위치별 예시 값. 인공지능 연결 전의 내용 공급 결과.
- `생성결과.json`: 예산·원본 무결성·한글 변환 성공 여부 기록.

## 이번 예시의 범위

대학 단독·단일단계·24개월(6+9+9개월)의 가상 연구계획이다. 공고 적격성을 판단한 결과가 아니다. 기업·국외기관·추가단계용 반복 양식과 조건부 별첨 예시는 출력에서 제외했지만 원본 및 두 MD에는 모두 남아 있다.

예산은 총 600,000천원이며 연차별 150,000 / 225,000 / 225,000천원으로 연결된다. 지원·부담기준, 참여자별 인건비와 장비별 세부 산출내역은 실제 자료로 확인해야 한다.

**실제 제출본이 아니다.** 인공지능 미연결 상태이며 자동 제출하지 않는다. 기관 등록번호, 공고번호, 연구실적, 승인·서명·직인은 임의로 만들어 넣지 않는다. 재직증명서 등 공식 증빙을 생성하거나 발급하지 않는다.

## 내부 구성

- `example_content.py`: 서울과기대 전용 예시 내용·예산.
- `generator.py`: 원본 위치 검증, 내용 입력, 조건부 예시 정리, 자료 묶음 생성. 외부 통신 없음.
- `govoffice/adapters/hwp_form_export.py`: 별도 프로세스·소유 문서에서 한글 변환. 전체 입력값·쪽 설정을 다시 읽어 검증.
- `template.hwp` / `source.hwpml`: 원본 사본 및 전체 서식 구조. 해시가 변경되면 생성을 중단한다.

HWPML(Hangul Word Processor Markup Language, 한글 문서 구조를 표현하는 마크업 언어)을 활용하므로 문서를 MD에서 다시 조립하지 않는다. 원본 표·글자 및 문단 스타일·쪽 설정을 가져온 후, 작성규칙에 따라 입력 내용은 본문 12pt·표 8pt 돋움을 적용한다. 긴 표지·요약문은 행이 잘리지 않도록 쪽 나눔을 허용한다.

향후 AI(Artificial Intelligence, 인공지능) 연결은 내용 공급자를 교체하는 작업이다. 원문 작성요령과 필요한 자료를 바탕으로 입력값만 반환하게 하고, 프로그램이 위치·필수값·분량·합계를 검증해야 한다. 아직 AI 호출 및 자동 제출 경로는 없다.
