범정부오피스 내부 설치판

1. 새 PC에 Windows용 한글 편집 프로그램을 설치해 주세요. 뷰어만으로는 작동하지 않습니다.
2. 받은 ZIP을 폴더에 모두 압축 해제해 주세요.
3. install.cmd를 일반 사용자 계정으로 더블클릭하세요.
4. 설치 점검을 통과하면 바탕화면과 시작 메뉴에 범정부오피스가 만들어집니다.

Python은 포함되어 있으므로 따로 설치하지 않아도 됩니다.
Windows 보안 설정 변경이나 관리자 계정 전환 없이 현재 사용자에게 설치합니다.
기관에서 스크립트 실행을 차단한 PC는 기관 담당자에게 실행 허용을 요청해야 합니다.

사용자 정보, 즐겨찾기, 프리셋은 %LOCALAPPDATA%\GovOffice\data에 저장합니다.
설치 로그는 %LOCALAPPDATA%\GovOffice\logs에 저장합니다.
새 버전은 다시 install.cmd를 실행하세요. 사용자 데이터와 이전 버전 파일은 유지됩니다.
기존 개발 PC의 개인정보와 프리셋은 이 설치판에 포함하지 않습니다.

이 배포판의 DLL은 32비트 한글용입니다. 비트수가 맞지 않으면 설치 점검에서 안내합니다.
설치 점검은 파일, 런타임, DLL 로딩, 레지스트리 등록을 확인합니다.
한글이 RegisterModule을 실제 승인하는지는 문서를 연결할 때 확인하며 실패를 성공으로 표시하지 않습니다.
새 PC에서 문서 열기, 선택 영역 저장, 프리셋 출력, 저장 후 닫기를 확인해 주세요.
환경 점검 통과가 모든 복원 기능의 동등 동작을 보증하는 것은 아닙니다.
