# 개발 문서 색인

프로그램 설계·동작 설명을 이 폴더에서 관리한다. 검증 결과는 [reports](../reports/), 검사 코드는 [tests](../tests/), 개발 도구는 [tools](../tools/)로 분리한다.

- [소주제별 자동작성](소주제_자동작성.md)
- [제목·디자인 표 보호](DESIGN_TABLE_PROTECTION.md)
- [출력 서식 보정](OUTPUT_POLISH.md)
- [본문 확인 메모](REVIEW_MEMOS.md)
- [양식의 디자인·내용 분리 저장](TEMPLATE_LAYOUT_DATABASE.md)

개별 문서에 쓰인 `reports/...` 경로는 `development/` 기준이다. 날짜별 구현·검증 설명은 당시 범위이며 최신 모든 기능의 검증 완료를 뜻하지 않는다.

연구개발 문서의 작성 기준과 레퍼런스 기억은 [프로젝트 공통 문서](../../../docs/README.md)에서 별도로 관리한다.
