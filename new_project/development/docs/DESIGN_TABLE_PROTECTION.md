# 제목·디자인 표 보호

## 수정한 원인

기존 판별은 폭이 좁은 숫자·간격 칸만 제외했다. 소주제에 빈 입력칸이 없을 때 제목 뒤에 문단을 추가하는 처리 때문에, 넓은 제목 셀과 `최종목표`·`세부목표` 항목명 셀에 본문이 들어갔다.

## 현재 규칙

- 한 줄 표의 번호 배지, 빈 간격 칸, 넓고 짧은 제목 칸이 함께 있는 구조는 전체 제목 막대로 보호한다. 색상이나 폭 하나만으로 입력 표를 막지 않는다.
- 제목 막대의 본문은 표를 포함한 문단 다음에 만든다. 번호·간격 칸은 입력을 차단한다.
- 일반 표에서 좁은 고정 항목명 옆에 넓은 내용 칸이 있으면 본문을 오른쪽 칸에 연결한다. 실제 내용 칸·자료 행·단일 본문 셀은 유지한다.
- 입력칸이 없는 표를 무조건 디자인으로 분류하지 않는다. 구조에 따라 디자인, 입력, 혼합, 정적 보존으로 구분한다.
- 원본 양식에서 매번 위치를 다시 계산한다. 저장 응답에 들어 있는 위치 지정값으로 보호를 우회할 수 없다.
- 응답의 필드 식별번호와 원래 연결 정보는 유지한다. 새 등록뿐 아니라 기존 등록 양식, 저장 응답 재사용, 다시 출력할 때도 적용된다. 원본·이전 출력본은 변경하지 않는다.
- 내용 칸의 분량 계산도 실제 이동할 위치를 사용한다. 출력 전 보호된 제목 문단이 변경되면 오류로 중단한다.
