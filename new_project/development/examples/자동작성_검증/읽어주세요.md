# 실제 AI 연결로 만든 가상 과제 예제

2026-09-10. 제출용 문서가 아니라 프로그램 연결·입력·저장 검증용이다.

- 파일: `가상과제_자동작성_검증예제_2026-09-10.hwp` (48쪽)
- 가상 주제: 대학 연구실의 실험 예약 현황을 정리하는 소프트웨어.
- 33개 소주제를 로그인된 Codex에 순서대로 요청했다. 사용자에게 프롬프트 복사·붙여넣기를 요구하지 않았다.
- 1,698개 값의 입력 위치와 쪽 여백을 한글 변환 후 다시 검사했다.
- 과제 기간·예산·기관·실적은 제공하지 않았다. 따라서 ‘확인 필요’ 및 빈칸이 많으며 오류나 누락 없는 제출본이라는 뜻이 아니다.
- 숫자 근거가 없어 예산 합계 55개 검사는 모두 ‘자료 부족’이다. 통과가 아니다.
- 일부 인력·세부 표·도형·조건부 별첨의 칸은 아직 자동 입력 대상이 아니다.
- 증빙·서명·직인·원본의 적용되지 않는 기관/연차/별첨은 사용자가 확인한다.

## 직접 실행할 때

범정부오피스 재실행 → 서울과학기술대학교 → **과제 문서 순차 작성**
→ **기후부 2026 연구개발계획서 · 순차작성 v2** 선택
→ 작성요령/입력 위치 확인 → 과제 정보 입력 → 로그인·외부 전달 동의 → **문서 작성**.

중단된 작업은 **이어서 작성**으로 재개할 수 있다. 이미 완료한 소주제는 재요청하지 않는다.
프롬프트는 AI(Artificial Intelligence·인공지능)에 전달하는 요청문이며, 프로그램이 작성요령과 과제 정보로 자동 조립한다.
