# 문서 작성 화면 · 계정 관리와 진행 화면 개선

## 반영 내용

- 공식 Codex 계정 조회 결과의 이메일과 요금제를 표시한다. 창을 열 때 백그라운드에서 조회한다. 비밀번호·토큰 파일은 읽거나 화면에 표시하지 않는다.
- 연결 해제는 `account/logout`을 호출하고 다시 조회해 해제를 확인한다. 이 PC의 공유 Codex 로그인에도 영향을 주므로 버튼을 누르면 안내 후 확인을 받는다. 다른 계정은 해제 후 AI 로그인으로 연결한다.
- 문서 작업 중 계정 변경을 화면과 백엔드 양쪽에서 차단한다. 계정 작업이 끝나기 전에는 새 작업 시작·재개도 차단한다.
- 01~03 단계 표시를 버튼으로 변경했다. 준비된 단계로 돌아갈 수 있고, 입력값 확인을 하지 않으면 03으로 갈 수 없다. 값을 수정하면 기존 확인이 해제된다. 잘못된 직접 입력값과 글자 수 제한을 확인한다.
- 입력값 화면에서는 우측 작업현황을 접고 개인 탭처럼 항목 목록과 큰 값 편집창을 나란히 제공한다. 수정 내용은 해당 필드 식별번호에 연결된다.
- 04 작업 진행 페이지에서 과제명, 현재 소주제, 실제 처리 단계, 소주제별 완료 상태, 작업 생성 당시의 작성 요청과 직접 입력값을 확인한다. 진행 중 정보는 읽기 전용이다.
- 보라색=진행, 초록색=완료, 주황색=중단/재개 가능, 빨간색=오류. 퍼센트는 실제 완료한 소주제 비율이며 AI 응답 대기·파일 저장에는 별도 움직이는 표시를 쓴다. 토큰 진행률이나 예상 시간을 추정하지 않는다.
- 기존 창 이동 중 폴링 차단 장치는 유지했다.

## 검증 범위

- Python 및 Windows 화면 회귀 테스트 55개 통과: 계정 메타데이터, 연결 해제 프로토콜·응답 확인, 작성 중 계정 변경 차단, 계정 작업 중 작성 차단, 단계 건너뛰기 차단, 확인 후 값 변경, 입력값 보존, 전용 진행 화면, 작업 정보 스냅샷, 기존 문서 작성·재개·창 이동 보호.
- 설치된 Codex 0.153.4가 생성한 공식 프로토콜 스키마에서 이메일·요금제 필드와 `account/logout`의 null 매개변수를 확인했다.
- 실제 계정 조회: 연결됨, 이메일 있음, 요금제 있음. 계정 식별정보는 검증 보고서에 기록하지 않았다.
- 연결 해제와 다른 계정 로그인 흐름은 모의 연결로 검증했다. 실제 사용자 계정은 로그아웃하지 않았다.
- 화면은 실제 화면 코드를 메모리에서 렌더링해 1180×840, 900×640에서 확인했다. 이미지에는 가상 계정·과제를 사용했다.
- 이번 변경에서 외부 AI 본문 생성이나 실제 한글 전체 출력은 다시 실행하지 않았다. 실행 중인 앱도 강제 종료·재시작하지 않았다. 이미 켜 둔 프로그램에는 재시작 후 반영된다.
