# AI 양식 분석 등록

## 구현

새 파일 등록 경로는 사본 읽기 → AI 분석 → 위치·형식 검사 → 불확실한 항목 재분석 → 원본과 분석 결과 저장으로 변경했다. 원문·표 좌표·글자색·문단 식별 위치를 전달하고, 문단마다 큰 주제·소주제·역할·작성 조건·작성요령 참조를 받는다. 본문 작성이나 외부 검색을 시키지 않고 도구 사용도 제한한다.

새 양식은 작성요령 MD 대신 `analysis.json`, `manifest.json`에 원문 작성요령과 해석·입력 위치를 함께 보관한다. 기존 등록본과 기후부 기본 양식의 기존 경로는 유지한다. 작업 프롬프트 및 조사 보고서 MD는 변경 대상이 아니다.

개인 저장정보와 AI 본문 작성칸은 명시적 역할로 구분한다. 개인값이 없는 칸은 AI에게 채워 달라고 보내지 않고 빈칸과 검토사항으로 남긴다. 원본 유지와 미확인 항목은 덮어쓰지 않는다. 확정된 작성요령 문단은 출력 시 글만 비우고 구조는 유지하며 복합 요소는 임의로 변경하지 않는다.

확인 필요 항목만 양식 선택 화면에 표시한다. 사용자 선택은 원본 유지, AI 본문, 저장 정보, 빈칸 유지이며 복합 문단은 원본 유지만 허용한다. 선택하지 않은 항목은 계속 원본 유지한다. 사용자 확인은 새 버전의 분석 파일로 저장하고 마지막에 목록 파일을 바꾸므로 도중 실패해도 기존 분석 참조는 유지한다.

문서 내용의 외부 전달과 계정 사용량 안내, 로그인 연결 전 등록 비활성화, 분석 진행 상태와 중단 버튼을 추가했다. 과제 주제·세부 내용은 등록 단계에서 입력받지 않는다.

## 검증 및 제한

관련 자동 시험 97개 통과. 실제 AI 예제의 분석 응답·저장 확인은 자동 시험 수와 별도다.

- 모의 AI로 분석 저장, MD 미생성, 원문 요령과 공통 조건 전달, 개인값 누락 시 AI 제외, 원본 고정문구 유지, 출력 위치 연결을 검사했다.
- 누락·중복·범위 밖 위치와 복합 문단 덮어쓰기를 거부하며, 형식 검사 실패 후 한 번 재요청하고 해결되지 않으면 확인 대상으로 남긴다.
- 여러 묶음의 문단 전체 처리, 중단·연결 오류 시 미완성 양식 미게시, 확인 항목의 연속 저장을 시험했다.
- 실제 화면 코드와 JSON 응답 경계에서 확인 항목 표시·선택 전송·미선택 항목 보존을 시험하고 `template_analysis_preview/01-analysis-review.png`를 확인했다.
- 실제 연결 시험은 첫 시도에서 자동 승인 검토 모델의 용량 오류로 차단됐다. 시험 코드가 고정된 공개 예제만 전송함을 읽기 검사한 뒤 동일 명령을 정식 승인 경로로 다시 요청했고, 승인 후 실제 AI 분석·검사·저장까지 성공했다. 우회 실행하지 않았다.
- 실제 AI는 7개 문단에서 이름 입력칸 1개, 작성요령 1개, 제목 1개를 식별했다. 의미가 불명확한 밑줄은 본문이라고 추측하지 않고 확인 대상으로 남겼다. 별도 작성요령 MD는 생성되지 않았다. 원문과 반환 결과는 `template_analysis_live_example/result.json`에 있다. 복합 요소를 불확실하다고 답한 경우 사용자에게 불필요한 확인을 요구하지 않고 프로그램이 보존하도록 이후 보완했다.
- 실제 연결 시험용 `development/tools/probe_template_analysis.py`는 개인정보 없는 가상 구조를 사용하며 계정 사용량이 발생한다. 포함된 HWP 이름의 시험 파일은 네이티브 문서가 아닌 시험용 자리표시자다. 실제 한글 파일 읽기·최종 한글 저장 전체를 새 경로로 실검증한 것은 아니다. 실제 문서 의미 해석 정확도를 보장하지 않는다.
- 의미 판단은 AI 결과이므로 오분류 가능성이 남는다. 원문 이미지의 시각적 해석은 하지 않으며 그림·복합 문단은 보존한다. 긴 문서의 멀리 떨어진 작성 조건은 누락될 수 있다. 최대 70문단·약 35,000자 단위이며 한 문단 자체가 60,000자를 넘으면 자동 분석을 중단한다.

사용자가 실행 중인 프로그램·한글 문서를 닫거나 재시작하지 않았다. 프로그램 재시작 후 새 양식 등록부터 적용한다.
