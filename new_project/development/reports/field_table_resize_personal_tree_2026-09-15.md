# 데이터 표 열 너비와 개인 탭 트리

## 적용

- 데이터 표 관리 및 문서 작성 입력정보 표의 맨 위 제목 셀 오른쪽 경계에 열 너비 조절 손잡이를 추가했다. 해당 열만 변경하고 이웃 열 너비는 유지한다. 최소 너비와 최대 2,000px 제한을 적용한다.
- 손잡이에 포커스가 있으면 좌우 방향키로 10px씩 조절할 수 있다. 필드 이동 드래그와 분리되어 저장된 필드 관계를 변경하지 않는다.
- 너비는 해당 창의 새로고침·수정 후 갱신과 작성 화면의 트리 재구성 동안 유지한다. 프로그램을 종료하거나 창을 새로 열 때까지 영구 저장하는 설정은 아니다.
- 개인 탭의 평면 목록을 대표필드 → 하위필드 → 개별 값 트리로 변경했다. 처음에는 펼쳐서 보여주며 새로고침 후에도 접은 항목은 접힌 상태를 유지한다.
- 이름이 같은 필드라도 고정 식별자와 부모 관계로 구분한다. 상단 요약 카드에 있는 기본 정보는 하위 필드가 없는 경우 중복 표시하지 않는다.
- 트리의 이름·값을 더블클릭하면 기존 편집창으로 수정한다. 기존 데이터 스냅샷 검증을 사용하고 저장 후 트리와 요약 정보를 갱신한다. 취소하면 저장하지 않는다.
- 개인 탭의 트리 영역은 기존 목록보다 높이를 늘렸다. 넘치는 데이터는 스크롤로 확인한다.

## 검증

- 관련 검사 34개 통과: 개인정보 표/데이터, 작성 흐름, 창 이동 보호 및 런처.
- 추가 화면 검사: 두 표의 DragDelta 이벤트, 한 열만 변경, 최소 너비, 갱신 후 너비 유지, 트리 부모·하위·값 구조, 동일 이름의 별도 필드, 접기 상태 유지, 이름 및 값 더블클릭, 편집 취소, 개인 탭 저장 후 재조회.
- `personal_tree_preview.png`: 가상 데이터로 실제 개인 탭을 렌더링하여 배치 확인.
- 사용자 문서나 개인정보 파일은 검사에서 수정하지 않았다. 실행 중인 프로그램을 강제로 재시작하지 않았으므로 새 화면은 재실행 후 적용된다.
