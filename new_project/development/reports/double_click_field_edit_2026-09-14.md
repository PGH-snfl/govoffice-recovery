# 개인 데이터·입력 정보 더블클릭 수정

- 개인 탭의 데이터 관리 표: 항목 이름을 더블클릭하면 이름 수정창, 값을 더블클릭하면 값 수정창을 연다. 확인하면 기존 필드 식별번호를 기준으로 저장한다. 기존 별칭·기본값·하위 관계의 처리는 기존 저장 로직을 유지한다.
- 두 번째 클릭에서는 드래그 시작 상태를 해제하여 수정과 드래그가 함께 실행되지 않도록 한다. 우클릭 메뉴와 기존 드래그 기능은 유지한다.
- 입력 정보 확인 표: 항목 이름과 값을 더블클릭해서 수정한다. 이름 영역과 접기·펼치기 화살표를 분리한다. 같은 표시 항목 아래 여러 문서 위치가 있으면 이름은 함께 바꾸되 각 위치의 값은 독립적으로 수정한다.
- 입력 정보 화면의 이름 변경은 현재 작성 화면의 표시 계층에 적용하며, 개인 탭 원본이나 저장된 양식은 변경하지 않는다. 위치 식별번호는 바뀌지 않는다. 값 변경은 기존 직접 입력값 검증·반영 경로를 사용한다.
- 취소 시 변경하지 않는다. 수정창은 열리면 입력창에 초점을 두고 기존 문자열을 선택한다. 문서 작업 중 편집은 차단하며 수정 후에는 입력 확인을 다시 받는다.
- 검증: 실제 화면 코드의 이벤트를 가상 데이터로 호출하여 더블클릭·취소·동일 이름의 값 분리·이름 변경·드래그 상태 해제·기존 드래그·진행 중 수정 차단을 확인한다. 실제 개인정보나 한글 파일을 변경하는 검증은 수행하지 않는다.
