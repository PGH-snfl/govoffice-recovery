# 번호별 양식 등록 및 읽기 쉬운 한글 작성

## 적용 내용

- 새 양식 등록 시 AI가 번호를 포함한 대·중·소주제 원문 위치를 반환하고, 번호 깊이와 원문 순서로 계층을 만든다. 숫자 상위 제목이 누락되면 의미를 지어내지 않고 `N번 중주제`라는 정리용 묶음을 만든다. 문서 본문에 이 가상 제목을 삽입하지는 않는다.
- 마크다운 정리본에는 제목과 해당 작성요령 원문만 저장한다. 문단 위치 주석·처리 설명을 제거했다. 안전한 재입력을 위한 내부 위치 정보 및 원본 사본은 별도 유지한다.
- 중주제 및 상위 주제 작성요령을 자식에 전달하되 형제 소주제 전용 요령은 섞지 않는다.
- 새 작업은 최소 조사 정책을 적용한다. 중주제 조사 결과 재사용, 문서당 최대 3개 조사 묶음, 요청당 웹 작업 최대 6회 및 출처 최대 3개를 요청한다. 실제 도구 호출 횟수 초과는 중단한다. 출처를 숨기거나 없애는 것이 아니라 본문 생성 자료에서 출처 메타데이터를 분리하고 `자료출처.json` 및 기존 조사 보고서에 따로 보존한다.
- `주제별_작성내용.json` 정리본은 `주제`, `작성내용` 두 항목만 가진다. 작업 상태·검증·출처·원본은 별도 보관한다.
- 표의 식별 가능한 빈칸도 입력 대상으로 연결한다. 금액·날짜·수량 등의 칸은 사실 확인형으로 표시하고 근거 없이 값을 만들지 않도록 요청한다. 서명·직인 칸과 복합 조절 요소는 자동 생성하지 않는다.
- 실제 줄바꿈 문단을 지원하고 생성된 문단의 위치 목록으로 저장 후 재검증한다. 문단의 정렬·줄 간격, 글꼴·크기·자간·장평은 양식 서식을 유지한다. 확인 필요 표식이나 검토 사유가 있는 작성 필드는 파란색으로 표시한다.
- 본문 칸이 없는 설명형 소주제/서론/결론 등에는 제목과 고정 내용을 보존한 채 새 본문 문단을 만든다. 인접 본문 서식을 상속한다. 학술지별 미제공 규정이나 새 표·그림 구조를 임의로 만들어 내는 기능은 아니다.
- 기존 양식을 새로 사용할 때도 출력 정책을 작업 사본에 적용한다. 등록 원본과 진행/완료 작업은 변경하지 않는다. 기존 양식의 번호 계층 정리본을 다시 만들려면 양식 재등록/재분석이 필요하다.

## 검증

- 번호 계층, 원문 순서, 중복 제목 독립성, 작성요령 상속, 표 입력, 여러 문단 위치, 파란색·서식 보존, 조사 재사용과 제한, 출처 분리 관련 시험 수행.
- 관련 회귀 시험 169개 및 화면 작업 흐름 시험 통과 후 로마 숫자 상위 계층 시험을 추가했다.
- 실제 한글 파일 생성/재열기 검증: `readable_authoring/readable_95604b5e/문단_표_파란검토표시_검증.hwp`.
- 가상 내용만 사용했다. 1쪽 검증 문서에서 입력 위치 3개(여러 문단 포함), 파란 글씨, 글자 크기, 자간/장평, 쪽 설정을 확인했다. 별도 AI 요청 없이 모의 응답으로 동작을 검사했으며 사용자 자료나 작성 중인 작업을 변경하지 않았다.
