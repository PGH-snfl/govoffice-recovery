# 등록 양식 삭제: 우회 처리 철회

## 변경

- 파일 이동 실패를 삭제 성공으로 바꾸던 삭제 기록 생성 및 목록 숨김을 제거했다.
- 등록 폴더가 삭제 보관 폴더로 실제 이동했을 때만 삭제 성공으로 응답한다.
- Windows 오류 5/32/33 발생 시 동일한 원자적 폴더 이동을 최대 4회 시도한다. 재시도 총 대기는 0.9초이며, 지속적인 잠금이나 권한 거부는 성공 처리하지 않는다.
- 보관 폴더 준비와 등록 폴더 이동 실패를 구분하고 출발/도착 경로 및 원문 오류를 표시한다. 실패 시 목록/입력값을 보존한다.
- 기존 삭제 기록 폴더는 조사 시점에 없었다. 사용자 등록 파일 삭제, 앱 종료, 권한 변경은 수행하지 않았다.

## 확인한 범위

- 임시 시험 파일을 삭제 공유 없이 열어 실제 WinError 5를 재현했다. 잠금 중 실패/목록 유지, 시험 핸들을 닫은 후 실제 폴더 이동 성공을 확인했다.
- 일시적인 오류가 해제될 때 같은 이동을 재시도해 성공하는 경우를 모의 시험했다.
- 삭제 전용 시험 13개 통과. 화면 동작 시험에서 실패 시 선택/목록 보존 및 성공 시 보관 안내를 확인했다.

## 남아 있는 확인

사용자가 보고한 오류의 전체 경로와 발생 동작은 아직 확인되지 않았다. 컴퓨터 제어로 조회한 현재 창 목록에는 범정부오피스 및 오류 창이 없었다. 일부 등록/보관 폴더의 읽기 권한 조회가 조사 환경에서 거부되었지만, 이것을 사용자 앱의 실패 원인이라고 확정할 수 없다. 실제 오류 화면의 전체 경로 확인 및 해당 작업 재검증 전에는 원인 해결 완료로 보고하지 않는다.
