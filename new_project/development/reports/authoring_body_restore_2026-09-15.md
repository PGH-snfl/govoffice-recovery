# 본문 작성 흐름 복구

## 변경

- `authoring_register_file`: 원문 사본 읽기 → 전체 문단의 본문/개인정보/고정 요소/작성요령 연결 → 문서 작성용 양식 등록으로 복구했다.
- `authoring_extract_guides`: 기존 AI 소주제·작성요령 MD 추출을 별도 요청과 별도 버튼으로 유지한다. 이 기능은 양식을 등록하거나 본문을 작성하지 않는다.
- `authoring_reanalyze_template`: 선택한 등록 양식의 원본 사본을 다시 분석하여 새 등록본을 만든다. 기존 등록본과 작업의 스냅샷은 변경하지 않는다.
- 등록 시 `include_body=True`로 기존 전체 문단 분석기를 사용한다. 제목/요령만 분석한 뒤 지역 규칙으로 빈칸을 연결하는 경로로 되돌아가지 않는다. 표 안의 본문 칸도 분석 대상이다.
- 본문 등록에서는 완성된 본문-작성요령 연결을 제목 전용 트리로 덮어쓰지 않는다.
- 본문 칸을 하나도 찾지 못한 등록은 실패 처리한다. 개인정보만 있는 기존 양식/이전 작업도 본문 작성 완료로 처리하지 않고 재연결을 안내한다.
- 기존 한글 출력과 비동기 출력본 열기는 유지한다.

## 검증

- Python 93개 테스트 통과: 등록 → 본문 작성 요청 → 본문 문구 반영 → 출력까지 모의 AI/모의 HWP 변환으로 검증했다. 표 속 본문, 재연결 시 기존 데이터 보존, 개인정보 전용 등록/재개 차단, 별도 MD 추출도 포함한다.
- PowerShell 화면/실제 콜백 probe 2개 통과. 등록과 추출 버튼 분리, 선택 양식에 대한 재연결 요청을 확인했다.
- 이번 변경 검증은 외부 AI 전송이나 실제 사용자 문서 재생성을 수행하지 않았다. 잘못 등록된 기존 양식은 새 코드 실행 후 ‘본문 작성 위치 다시 연결’을 실행해야 한다.
