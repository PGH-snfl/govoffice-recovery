# 문서 작성 워크플로우 변경 검증

2026-09-10. 내부용 기능 변경. 실제 사용자 문서·프로필은 시험 중 변경하지 않았다.

## 반영 사항

- 첫 화면에서 저장된 양식을 선택하며, 없으면 새 HWP 양식을 등록한다.
- 새 등록은 개인 탭과 연결된 이름·전화번호·이메일 확인을 함께 진행한다. 기존 추가 프로필은 보존한다.
- 양식별 하위 `guides/` 라이브러리에 큰 주제별 MD 파일을 만들고, 파일 안에 소주제별 표 작성요령과 파란 주석을 보존한다.
- 출력 입력값과 AI 작성 칸을 별도로 확인한다. 빈 직접 입력값은 빈칸으로 유지한다.
- 입력값을 원본 사본에 먼저 채운 뒤, 사용자 작성 요청과 소주제별 요령을 AI에 전달한다. 직접 입력 칸은 AI 응답 대상에서 제외한다.
- 중단·재개 시 직접 입력값과 완료된 결과를 보존한다.
- 임의 양식은 빈칸·항목명·소주제의 후보 검토가 필요하다. 빈칸을 못 찾으면 명시적으로 중단한다.

## 검증 결과

- 관련 Python 및 Windows 화면 구성 시험 합계 120개 통과.
- 화면 구성요소 37개 생성, 초기 양식 선택 화면, 입력값 양방향 연결 확인.
- 실제 화면 코드의 등록 → 사용자 정보 저장 → 입력값 확인 → 작성 요청 버튼 흐름을 모의 응답으로 시험했다. 화면은 표시하지 않았다.
- 직접 입력값이 AI 호출 전에 문서 사본에 존재하는지, 요청에서 빠지는지, 최종 결과에서 보존되는지 확인했다.
- 빈 직접 입력값, 잘못된 위치·길이·제어 문자 거부, 재개 시 값 보존 확인.
- 일반 양식 안내 정리 시 원래 표 흐름과 글자 크기 보존 확인.
- 창 이동 중 타이머 차단·복구 시험 유지 확인.

## 미실행 범위

실제 로그인한 AI와 설치된 한글을 함께 사용한 새 전체 문서 생성, 눈으로 확인하는 실제 창 동작·쪽 배치 검증은 이번 변경에서 수행하지 않았다. 기존 실검증 기록을 이번 워크플로우의 실검증으로 간주하지 않는다.
