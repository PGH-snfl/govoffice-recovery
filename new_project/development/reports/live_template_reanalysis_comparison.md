# 실제 AI 양식 재분석 비교

실행일: 2026-09-28

## 실행

범피스의 `양식 다시 분석` 동작을 기존 「연구개발제안서 · 저장응답 재사용용」에 실행했다.
연결된 ChatGPT 계정으로 AI 분석 요청 1회가 전송됐다. 입력 데이터는 한글 원본의 내용 있는
문단 443개, 약 6,484자였다. AI는 제목·작성요령의 원문 문단 위치만 반환했고,
프로그램은 그 위치의 원문 문구를 새 등록본에 복사했다. 본문을 새로 생성하지 않았다.

## 기존 등록본과 비교

| 항목 | 기존 등록본 | AI 재분석본 |
|---|---:|---:|
| 주제 | 39개 | 38개 |
| 전체 입력 위치 | 169개 | 129개 |
| 개인정보 입력 위치 | 31개 | 31개 |
| 본문 입력 위치 | 138개 | 98개 |
| 연결된 작성요령의 고유 원문 위치 | 71개 | 72개 |

입력 위치 129개는 양쪽이 같았고, 이름·역할이 달라진 공통 위치는 없었다.
기존 본문 입력 위치 40개는 재분석본에서 빠졌다. 모두 요약문 영역에 속한다.

주제 제목 문단 271의 「요약문」과 바로 연결된 `요약문은 5쪽 이내로 작성` 지침을
AI가 놓쳤다. 프로그램은 AI가 발견한 주제 아래에서만 빈칸을 연결하므로,
이 누락 때문에 요약문 입력칸 40개가 새 등록본에 연결되지 않았다.
즉, 입력 위치 차이는 AI가 작성칸을 판정한 결과가 아니라 AI의 제목 누락에 뒤이어
프로그램의 로컬 빈칸 연결이 달라진 결과다.

작성요령은 기존과 70개 위치가 일치했다. 기존 지침 1개가 빠졌고,
AI가 `구분`, `구체적인 내용`이라는 표 제목 셀 2개를 작성요령으로 잘못 연결했다.
연결된 문구 자체는 모두 원문과 일치하며, 새 문장을 지어내지는 않았다.

## 판단

프로그램은 결과를 `부분 분석`으로 저장했다. 새 등록본은 기존 등록본을 덮어쓰지 않는다.
다만 요약문 입력칸이 빠져 있으므로 현재 상태를 문서 작성용 완성 양식으로 쓰면 안 된다.
AI 분석 후에도 주제·작성요령 누락과 표 머리글 오연결을 사람이 확인해야 한다.
