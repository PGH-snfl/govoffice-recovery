# 문서 작성 두 단계 화면 변경

## 적용 내용

- 번호가 표시되는 화면: 01 양식 선택 → 02 작성 내용.
- 필수 작성 입력은 작성 주제와 주제 세부 내용뿐이다. 추가 사실/자료 입력란, 검토 체크박스, 동의 체크박스, 등록 시 개인정보 재입력 화면을 제거했다.
- 선택한 양식에 정확히 연결되는 개인 탭의 저장값만 표시한다. 빈 값, 미연결 항목, AI 본문 후보는 숨긴다.
- 동일한 개인 필드는 한 줄로 묶되 모든 문서 대상 ID를 보존한다. 값을 수정하면 대상 칸 전체에 반영한다. 서로 다른 개인 필드를 이름이나 값만으로 병합하지 않는다.
- 값 더블클릭 수정은 해당 작업에만 반영한다. 원본 개인 프로필은 변경하지 않는다.
- 개인정보가 없어도 두 입력만으로 시작할 수 있다. 양식에 자동 입력 위치 자체가 없거나 값이 허용 길이를 넘으면 기존 안전 검증은 유지한다.
- 시작 버튼 위에 외부 전달 범위를 표시한다. 별도로 저장한 개인 값은 AI 요청 대상에서 제외하며, 양식 원문의 정보는 포함될 수 있음을 안내한다.
- 사전 검토를 완료했다고 자동 기록하지 않는다. 새 화면은 review_mode=final_output, preflight_reviewed=false를 기록한다.
- 작성 중에는 단계/계정/입력 화면을 숨기고 진행률과 현재 작업을 보여준다. 중단·오류 시 재개할 수 있다.
- 완료 화면에는 처리 요약과 최종 한글 파일 열기 버튼만 둔다. 사실·수치·증빙 등의 최종 검토는 한글 출력본에서 한다. submission_ready=false 유지.

## 코드

- document_authoring_flow_ui.ps1: 새 두 단계 및 진행/완료 화면.
- document_authoring_ui.ps1: 공통 트리 표, 개인 정보 전용 표시, 창 격리 래퍼. 기존 대형 화면 함수는 새 파일로 교체했다.
- services/authoring_inputs.py: saved_profile_rows, 개인 필드 기준 중복 제거와 문서 대상 목록 보존.
- services/authoring_commands.py: 저장된 정보 준비 및 최종 출력본 검토 모드 전달.
- services/document_authoring.py: 최종 출력본 검토 모드 기록. 기존 순차 작성·서식 출력·검증·개인 값 보호 유지.
- launch_gui.ps1, packaging/build_internal_release.py, 진단 실행기: 새 화면 파일 연결.

## 검증

- 관련 자동 시험 72개 통과: authoring_workflow, document_authoring, authoring_validation, profile_table_ui, window_poll_guard, deployment.
- 실제 화면 함수의 버튼/더블클릭 이벤트를 모의 처리기로 실행: 새 양식 선택, 단계 잠금, 저장값 수정·취소, 중복 대상 일괄 반영, 빈 프로필, 두 필수 입력, 진행·오류·재개·완료.
- 기존 창 재개방·타이머 격리·드래그 중 상태 확인 중단·열 너비 조절 시험 통과.
- 화면 이미지 생성 후 입력/개인정보/진행/완료 배치를 확인했다. 이미지는 authoring_two_stage_preview 폴더에 있다.
- 실제 외부 AI 호출이나 새 한글 문서 생성은 이번 검증에서 실행하지 않았다. 모의 작성기와 모의 한글 저장기를 이용했다.
- 사용자의 실행 중 프로그램, 한글 문서, 개인 프로필은 변경하지 않았다. 프로그램을 다시 실행해야 새 화면이 로드된다.
