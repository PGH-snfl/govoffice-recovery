# 개인정보 결과 창 이동 시 멈춤 조사

## 증상과 확인 범위

- 사용자 보고: 선택 영역 분석 결과가 표시된 뒤, 결과 창 자체를 끌어 옮기면 마우스를 포함해 컴퓨터 전체가 멈춤.
- 결과 창은 기본 Windows 제목 표시줄로 이동하며, 데이터 필드 드래그 처리와 별개임.
- 기존에는 결과 창의 `ShowDialog()` 중에도 문서 상태 타이머(1.5초)와 선택 감지 타이머(0.1초)가 유지됨. 요청 중복 방지는 한 요청이 진행되는 동안만 적용되고, 결과 검토 기간에는 적용되지 않았음.
- 선택 감지는 전면 창이 Hwp인지 검사하므로, 결과 창 이동을 무조건 문서 선택으로 오인한다고 단정할 수 없음.
- 전체 시스템 멈춤의 직접 원인은 아직 확인되지 않음. 아래 변경은 확인된 불필요한 백그라운드 호출 경로를 제거하는 조치이며, 시스템 멈춤의 재현·해소를 입증한 것은 아님.

## 변경

- 개인정보 분석 시작부터 결과 창 종료까지 두 자동 조회 타이머를 중지함. 데이터 표 관리 창에도 동일하게 적용함.
- 이미 대기열에 들어온 타이머 콜백도 검토 중에는 바로 종료함. 사용자가 명시한 분석·저장 요청은 허용함.
- 정상 종료 및 예외 발생 시 원래 켜져 있던 타이머만 복구함. 앱 종료 중에는 재시작하지 않음.
- 중복 결과 창 실행을 방지하고, 시작·종료 시 미완성 마우스 선택 상태를 비움.
- 단계·항목 수·소요 시간만 진단 기록에 남김. 추출한 개인정보 값은 기록하지 않음.
- 기존 선택 영역 추출 알고리즘과 프리셋 기능은 변경하지 않음.

## 검증

- 관련 자동 검사 115개 통과: 개인정보 화면·저장, 선택 영역 추출, 한글 연결 어댑터, 백엔드 통신.
- 새 격리 검사는 실제 창이나 한글을 열지 않고 타이머 대역과 실제 콜백으로 검토 중 자동 요청 차단, 중복 실행, 종료·예외 시 복구, 앱 종료 시 재시작 방지를 확인함.
- 기존 화면 검사는 창 표시를 대역으로 바꾸어 필드 이동·수정·선택 항목 저장을 확인함.
- 전체 컴퓨터 멈춤 위험 때문에 실행 중인 프로그램에서 제목 표시줄을 드래그하는 재현 시험은 하지 않음. 재발 여부 확인은 미완료.
