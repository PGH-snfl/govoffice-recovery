# 주제별 자료조사·분석 기반 문서 작성

## 변경 내용

기존의 도구 없는 본문 작성 앞에 독립된 자료조사 요청을 추가했다. 작성요령과 작성 주제·세부 내용을 토대로 조사 질문을 설정하고 공개 웹 검색·원문 확인, 자료 비교·적용 한계 분석, 추진 방법·위험 대응·평가 지표 제안까지 수행한 뒤 구조화된 근거를 본문 작성 요청에 전달한다.

필수 입력은 여전히 두 개이며 새로운 확인 단계는 추가하지 않았다. 진행 화면에는 검색·분석·본문 작성·문서 반영 상태를, 완료 화면에는 조사한 주제·출처 수를 표시한다. 출력 파일 열기 외의 완료 버튼은 추가하지 않았다.

조사 결과에는 사실, 제안, 불확실성, 출처를 구분한다. 출처 참조·자료형·문자 수·URL 형식을 검사하고 실제 웹 실행 이벤트 없이 조사 완료 처리하지 않는다. 이 검사가 원문의 사실성이나 AI 해석을 보증하지는 않는다.

## 실제 연결 확인

설치된 `codex-cli 0.154.0-alpha.6.2`의 공식 App Server 연결로 실행했다. 사용자 계정을 바꾸거나 로그아웃하지 않았다. 공개 예제 외에 사용자 개인정보나 실제 과제 양식은 전송하지 않았다.

- 예제: 도시 열섬 완화를 위한 공공시설 주변 그늘·녹지 효과와 비교 관측 계획.
- 실제 웹 작업 완료 이벤트 3개 수신: 검색·페이지 열기·페이지 내 찾기. 한 이벤트가 복수 검색을 포함할 수 있어 개별 HTTP 요청 수를 의미하지 않는다.
- 반환된 공식 출처 2개: 미국 환경보호청 기술자료, 미국 국립기상청 관측 지침.
- 조사 결과를 실제 본문 작성 요청에 전달하여 1,313자 본문 수신 및 필드 형식 검사 성공.
- 본문에는 확정된 사실과 예비 관측 설계가 구분되고 해외 자료 적용 한계와 미확정 예산 등이 남았다.
- [실제 받은 조사·근거 문서](research_live_example_2026-09-15/자료조사_근거.md)
- [실제 받은 본문](research_live_example_2026-09-15/작성결과.md)
- 실행 도구: `development/tools/probe_authoring_research.py`. 수동 실행해야 실제 계정 사용량이 발생한다.

이번 실제 시험 범위는 공개 자료 조사 → 근거 전달 → 본문 수신이다. 한글 프로그램을 통한 최종 저장 전체를 실제 실행한 시험은 아니다. 해당 연결 흐름과 문서 반영은 별도로 모의 에이전트·내보내기를 사용해 회귀 시험했다.

## 발견·수정한 연결 문제

제한된 실행 환경에서만 계정 연결 프로세스가 시작 직후 종료됐으며, 승인된 실행 환경에서 기존 로그인 연결은 정상 확인됐다. 이어서 작업별 설정 병합에서 따옴표가 포함된 점 표기 서버 이름이 새 이름으로 해석되는 문제, 정규화된 기본 설정 전체를 다시 전달하면 빈 값의 자료형이 달라지는 문제를 확인했다. 정확한 이름의 중첩 설정에서 `enabled=false`만 병합하도록 수정한 뒤 실제 조사와 작성이 성공했다. 개인 설정 파일은 변경하지 않았다.

## 회귀 시험 범위

관련 자동 시험 86개 통과: 연결, 자료조사, 문서 작성, 작성 흐름, 자동 검사, 개인 정보 표. 실제 연결 예제와 화면 렌더링 검증은 이 개수와 별도다.

- 조사 요령 전달, 근거·제안의 작성 프롬프트 반영, 출처·보고서 저장.
- 출처 없는 사실, 존재하지 않는 참조, 비공개 주소, 다른 소주제 응답 차단.
- 중단 시 본문 호출 금지, 재개 시 완료 조사 재사용, 누락된 MD 재생성과 조회일 보존.
- 개인 저장값을 조사·본문 요청에서 제외하고 직접 연결한 문서 칸에만 반영.
- 조사 단계의 웹 허용, 작성 단계의 도구 금지, 다른 도구 요청 중단, 웹 작업 상한 감지.
- 실제 화면 구성요소를 사용하는 두 단계·진행·완료 화면 시험. 새 작업 조사 활성화와 완료 요약 검사.
- `authoring_research_preview/`의 진행·완료 화면을 렌더링하고 작은 화면에서 문구와 버튼을 확인했다.

## 운영 범위

조사에는 추가 시간과 계정 사용량이 든다. 소주제마다 웹 작업 최대 24회를 요청하고 초과 이벤트를 감지하면 중단한다. 형식 오류 재요청은 한 번 허용한다. 조사 결과는 작업 폴더의 `research/`에 저장하고, 최종 `자료조사_근거.md`로 모은다. 오류 후 재개 시 이미 끝낸 조사는 다시 수행하지 않는다.

조사 요청에서만 공식 제공 웹 도구를 켠다. 명령·파일 변경·개인 연결 서비스는 작업별 설정으로 제한한다. 실제 실험·기관 협의·구매·게시·제출은 수행하지 않는다. 단순 계산과 분석 제안이 실제 실험 검증을 의미하지 않는다. 개인정보가 작성 주제·설명·원본 요령에 포함되면 AI에 전달될 수 있으며 완전한 자동 비식별화를 보장하지 않는다.

프로그램 재시작 후 새로 시작하는 문서 작성에 적용된다. 기존 작업의 활성화 여부는 유지한다. 이 작업 중 사용자 프로그램이나 한글 문서를 강제로 닫거나 다시 실행하지 않았다.

공식 규격: [App Server](https://learn.chatgpt.com/docs/app-server), [웹 검색](https://learn.chatgpt.com/docs/web-search).
