# 입력 정보 확인 화면: 개인 탭 방식의 계층형 데이터 표

## 변경

- 02 입력값 확인의 평면 목록을 `대표항목·소주제 → 하위항목 → 직접 입력값 → AI 본문` 표로 변경했다.
- 개인 탭의 데이터 관리 표처럼 같은 상위항목 셀을 세로 병합한다. 화살표로 가지를 접거나 펼친다.
- 값 클릭 시 오른쪽 큰 입력창에서 수정한다. 표에도 수정값이 즉시 표시된다.
- 개인 데이터의 이름·전체 경로·별칭이 정확하고 유일하게 일치하는 경우 그 필드의 부모 관계를 표시한다. 동일 별칭 후보가 여럿이거나 유사한 이름뿐이면 임의로 부모를 고르지 않는다. 양식에 명시된 `상위 > 하위` 이름도 구분한다.
- 표의 묶음은 표시용이다. 같은 이름 아래 여러 문서 입력칸이 있어도 위치 식별번호와 값은 각각 보존한다. 개인 탭에 저장된 원본 데이터와 문서 양식은 변경하지 않는다.
- AI 본문 토글, 모두 보기, 수정 후 재확인, 다음 단계 제한, 작업 중 수정 금지와 기존 창 이동 보호를 유지한다.

## 검증

- 관련 자동 테스트 50개 통과(입력 경로·개인 데이터 대응, 작성 워크플로우, 문서 작성, 창 이동 보호).
- 실제 화면 코드에 가상 데이터를 넣어 세 단계 계층, 동일 이름의 두 입력칸, 부모 셀 세로 병합, 접기·펼치기, 값 독립 수정, AI 토글·필터, 다음 단계 입력값 전달을 검증했다.
- 1180×840 및 900×640 렌더링 확인. 작은 창이나 깊은 계층은 스크롤로 확인한다.
- 화면 자료: `../screenshots/authoring_input_tree_20260914/03-inputs.png`
- 실제 계정 변경·외부 AI 호출·한글 출력은 실행하지 않았다. 실행 중인 앱도 강제 재시작하지 않았다.
