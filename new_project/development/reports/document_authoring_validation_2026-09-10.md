# 소주제별 자동작성 검증 — 2026-09-10

## 범위

사용자 요청에 따라 실제 과제 자료를 받지 않고 가상 예제로 시험했다.
내부용 프로그램이며 외부 제출·증빙 생성은 수행하지 않았다.

## 구현 보완

- 기후부 양식의 33개 소주제 모두에 입력 위치를 연결했다. 총 1,698개다.
- 일정·기여도·실적·표준화·규제샌드박스·장비·기관현황·부담계획·별첨 일부의 기존 미연결을 보완했다.
- 표의 행·열 제목을 요청문에 넣고 일정표 표식을 제한했다.
- 등록된 작성요령 표와 파란 안내는 출력에서 정리하되 MD 원문에는 보존한다.
- 제거 후 입력 위치를 다시 계산하고 한글에서 정확한 위치별 값을 검증한다.
- 삭제된 안내 앞부분의 쪽 설정을 첫 문단으로 옮긴다. 빈 첫 장을 만들던 표 배치를 보정했다.
- 예산 합계, 미확정 값, 출력 위치, 알려진 원본 예시 표식을 검사한다.
- 새 양식 등록 후 새 등록본 선택, 최신 양식 우선 표시, 오류 안내 유지 등을 보완했다.
- 변환 오류가 문서 닫기 오류에 가려지지 않게 했다.

## 실제 연결 시험

- Codex CLI(Command Line Interface·명령형 실행 도구) 0.153.4의 공식 App Server 연결 사용.
- 기존 ChatGPT 로그인 상태에서 실행. API 키로 전환하지 않았다.
- 가상 과제: 대학 연구실 실험 예약 현황 정리 소프트웨어. 기간·예산·기관·실적 미확정.
- 33개 소주제 모두 실제 응답 저장. 형식 보정 재요청 1회를 포함해 실제 응답 34회.
- 최초 저장 단계는 시험 시작 당시 로드된 쪽 설정 정리 코드 때문에 실패했다.
  완료된 응답 33개를 그대로 두고 수정된 코드로 저장 단계만 재개했으며, 추가 AI 요청 없이 성공했다.
- 최종 상태 `completed`, 한글 48쪽, 196,608바이트.
- 1,698개 입력값·정확한 문단 위치 일치. 쪽 크기·여백 일치. 원본 변경 없음.
- 작업 식별번호: `1f39f05158884c4f9535b4238d5d7b94`.

## 검사 결과

- 관련 자동 시험 94개 통과: 작성 서비스, 연결, 검사 규칙, 기존 기후부 기능, 화면 통신, 기관 목록 및 배치 등.
- 화면 정의 구문 검사와 21개 구성요소 생성·한글 입력·동의 기본 해제 검사 통과.
- 원문 3,074개 비어 있지 않은 문단은 작성요령/문맥 MD에 모두 보존되는 것을 시험했다.
- 작성요령 파일 34개: 공통 1개 + 소주제 33개.
- 출력에 등록된 작성요령 표 0개, 알려진 예시 표식 0개, 위치 검사 오류 0개.
- 숫자가 제공되지 않아 예산 합계 55건 모두 `not_enough_data`(자료 부족). 숫자 검증 통과로 표시하지 않았다.
- 미확정 표식 포함 값 929개. 나머지가 사실 검증 완료라는 뜻은 아니다.
- 48쪽 전체 축소 미리보기와 표지·예산표 등 확대 미리보기를 확인했다. 빈 첫 장 없이 출력되며 입력 표/본문을 확인했다.
- 자동 시각 검수 완료 플래그는 켜지 않았다. 이후 실제 입력 분량의 쪽 배치는 다시 확인해야 한다.
- 실제 화면의 마우스 클릭 검증은 완료하지 못했다. 별도 시험 창이 화면 제어 도구에 노출되지 않아 생성/구문 시험으로 범위를 한정했다. 시험 전용 프로세스는 종료했다.

## 남은 경계

- 모든 소주제에 입력 위치가 있다는 것과 양식의 모든 칸이 자동화됐다는 것은 다르다.
- 일부 인력·세부 내역표·추진체계 도형·조건부 별첨은 수동 작성 대상이다.
- 검은 안내 문구, 원본 빈칸·일부 예시, 조건부 양식, 서명란이 남는다. 모든 안내/예시가 제거됐다고 보장하지 않는다.
- 과제 유형 선택에 따른 불필요한 기관·연차·별첨 삭제, 증빙 확인, 서명·직인 입력, 자동 제출은 하지 않는다.
- 임의로 등록한 다른 양식은 번호형 소주제/글머리표 탐지 수준이며 기후부 전용 연결과 동일하지 않다.
- 계정 사용 한도·연결 문제·한글 오류가 발생하면 완료된 응답을 보존하고 오류를 표시한다.
