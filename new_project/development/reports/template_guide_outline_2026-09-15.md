# 대주제·소주제·작성요령 연결표

## 변경

- AI에 대주제와 소주제의 소속 관계 및 원문 요령의 위치 연결만 요청한다. 확실한 항목의 설명은 비워 두도록 요청한다.
- `manifest.json`의 `guide_outline`은 대주제·소주제·원문 요령, 별도 공통 요령, 미연결 위치만 담는다. 입력 필드·역할·처리 설명은 별도 저장 구조를 유지한다.
- 전체 공통 요령이 각 소주제에도 중복 저장되던 것을 제거했다. 조사·작성 요청은 현재 소주제 요령과 해당 대주제의 공통 조건, 문서 전체 공통 요령만 사용한다. 다른 소주제의 전용 요령을 섞지 않는다.
- 같은 제목은 이름으로 합치지 않고 원문 위치로 구분한다.
- 양식 선택 화면에 ‘주제별 작성요령 보기’를 추가했다. 읽기 전용 트리이며 펼칠 때만 불러온다. 같은 분석 버전은 다시 불러오지 않고, 수정된 분석 버전은 갱신한다. 주기적인 목록 갱신에는 전체 요령을 보내지 않는다.
- 기존 양식과 진행 중 작업은 자동 재분석·수정하지 않는다. 새로 등록하는 양식부터 적용된다.

## 검증

- 관련 자동 시험 128개 통과. 새 계층 시험 5개 포함: 구조/원문 보존, 소주제별 자료 격리, 대주제 조건의 적용 범위, 조사 요청의 동일한 연결 사용, 읽기 전용 조회.
- 실제 화면 구성요소 시험: 트리의 공통/대주제/소주제/요령 표시 및 재열기 캐시 확인. 기존 단계 이동·입력 잠금·개인 정보 표·완료 흐름도 통과했다.
- 실제 AI 연결: 대주제 2개, 소주제 3개, 원문 요령 6항목이 있는 가상 예제에서 요청 2회, 분석·저장 16.29초. 소주제 번호에 맞는 요령 연결 및 공통 요령 분리를 확인했다.
- 앞선 모호한 가상 예제의 응답은 요령 연결 검사를 통과하지 못해 6항목을 확인 대상으로 보존했다. 성공으로 처리하지 않았으며, 최종 검증은 적용 소주제 번호를 명시한 별도 예제로 수행했다.
- 실제 AI 시험은 가상 문단과 자리표시자 HWP를 사용했다. 실제 한글 문서 열기/출력 및 큰 양식의 분석 시간 측정은 아니다.
