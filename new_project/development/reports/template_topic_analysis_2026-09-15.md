# 주제·작성요령 전용 양식 분석

## 적용 내용

새 양식 등록에서 AI의 업무를 제목 확인과 작성요령 연결로 제한했다. 일반 본문·빈칸·개인 탭 저장값은 분석 요청에서 제외한다. 입력 칸과 개인 정보 항목명 연결은 프로그램에서 처리한다.

작성요령 표 전체 원문과 표 밖 파란 주석을 보관한다. 제목과 긴 파란 조건이 같은 문단에 있으면 제목을 따로 후보로 만들되 원래 문단은 유지한다. 한 표에 여러 소주제의 요령이 있을 때는 AI가 원문 문단 번호별로 해당 주제를 연결할 수 있다. 공통 요령도 별도로 연결한다. 원문을 다시 쓰거나 요약해서 대체하지 않는다.

제목 요청 1회 + 요령 요청 최대 3회, 자동 재요청 없음. AI 요청 단계는 240초의 협력적 중단 예산을 사용한다. 예산·요청 크기·요청 횟수 제한으로 처리하지 못한 자료는 삭제하지 않고 부분 분석으로 저장한다. 사용자 중단이나 연결 오류는 정상 등록 완료로 처리하지 않는다. 전체 한글 읽기·연결 초기화·저장에 대한 강제 5분 종료 보장은 아니다.

## 입력 위치의 안전 처리

- 원문 문단 번호와 한글 원본 사본은 유지한다.
- 이름·전화·이메일 및 개인 탭의 필드명·별칭은 로컬에서 대조한다. 프로필 값은 AI에 보내지 않는다.
- 동일 셀의 반복 빈 문단을 각각 필드로 만들지 않는다. 셀의 기존 내용 앞에 있는 빈 문단도 보존한다.
- 용도를 판단하지 못한 빈칸은 자동 입력하지 않고 집계·기록한다. 수천 개의 빈칸마다 확인 선택창을 만들지 않는다.
- 용도가 모호한 명시적 입력 표시나 제목·요령은 확인 대상으로 남긴다. 확인 전에는 원본을 보존한다.
- 빈칸이 있다는 이유만으로 모든 칸을 AI 본문으로 만들지 않는다. 범용 양식의 입력 위치 자동 판별은 보수적이므로 최종 문서 확인이 필요하다.

## 검증

- 관련 자동 시험 123개 통과: 새 분석 17개, 기존 분석/문서 작성/자료 조사/외부 연결/개인 표/작업 흐름 회귀 시험 포함.
- 기존 기후부 양식 7,419문단의 로컬 모의 비교: 요청 105 → 2회, 프롬프트 1,702,756 → 66,636자. 모의 제목 판정에 따라 실제 요청 크기는 달라질 수 있다.
- 이전 추출 기준의 작성요령 표 23개, 표 요령과 표 밖 파란 주석 526개 항목의 원문이 모두 일치했다. 누락 0개. 모든 원문 위치가 결과에 남았다.
- 작은 가상 양식으로 실제 AI 요청 2회, 분석 및 저장 14.13초. 제목 1개, 요령 1개, 로컬 본문 칸 1개, 개인 정보 칸 1개를 확인했다.
- 실제 연결 시험은 가상 문단 자료이며 `.hwp`는 자리표시자다. 실제 한글 파일 열기·내보내기 시험이나 큰 원본 양식의 전체 AI 시간 측정은 아니다.

## 주요 파일

- `src/govoffice/services/template_topic_analysis.py`: 후보 추출, 주제·요령 전용 요청, 위치 검증, 로컬 입력 판정, 요청 예산.
- `src/govoffice/services/template_analysis.py`: 새 등록 경로, 원문 요령·분석 기록 저장, 여러 소주제 연결, 부분 분석 상태.
- `src/govoffice/services/authoring_commands.py`: 개인 필드명·별칭의 로컬 전달.
- `document_authoring_flow_ui.ps1`: 전송 범위 안내와 부분 분석 상태 표시.
- `development/reports/template_topic_analysis_benchmark.json`: 원본 양식 로컬 비교 수치.
- `development/reports/template_topic_analysis_live_example/result.json`: 가상 양식 실제 AI 연결 결과.

사용자 앱과 한글을 강제로 종료하거나 재실행하지 않았다. 새 코드로 다시 실행한 뒤 새로 등록하는 양식부터 적용된다.
