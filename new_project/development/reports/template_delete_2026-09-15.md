# 등록 양식 삭제

- 양식 선택 화면에 ‘선택한 양식 삭제’ 버튼과 취소가 기본인 확인 창을 추가했다.
- 삭제 범위는 선택된 양식 번호의 등록 폴더 한 개다. 앱 데이터의 `deleted_templates`에 고유 보관 번호로 이동한다. 목록 조회에는 이 보관 폴더가 포함되지 않는다.
- 파일명이나 양식 이름을 경로로 사용하지 않는다. 양식 번호, 폴더 위치, 심볼릭 링크·정션 여부를 검사한 후 이동한다. 삭제 보관 위치가 외부 연결이면 거부한다.
- 원본 한글 파일, 개인 프로필, 기존 작업의 양식 사본, 출력 문서는 유지한다. 기존 작업은 등록본 삭제 후에도 자기 사본으로 계속 작성할 수 있다.
- 삭제 후 선택 정보·입력 준비 상태·요령 트리 캐시를 정리한다. 마지막 양식을 삭제해도 다음 단계와 삭제 버튼이 안전하게 비활성화된다.
- 양식 처리 및 문서 작성 중에는 서버와 화면에서 삭제를 제한한다. 확인 창이 떠 있는 동안 화면 갱신을 막아 중복 요청을 방지한다.
- 복구 가능한 보관 방식이며, 앱 내 복원 버튼은 이번 범위에 포함하지 않았다.

검증: 삭제 전용 자동 시험 7개 및 관련 회귀 시험 포함 135개 통과. 화면 구성요소 시험에서 취소/승인/목록 갱신/입력 초기화/작업 중 비활성화/마지막 양식 삭제를 확인했다. 삭제 시험은 임시 가상 양식으로만 수행했으며 사용자의 실제 등록 양식은 삭제하지 않았다. 사용자 프로그램을 강제로 재시작하지 않았다.
