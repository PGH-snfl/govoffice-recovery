# 소주제·작성요령 등록 → 자료조사 → 본문 작성

이 변경은 직전 `authoring_body_restore_2026-09-15.md`의 전체 문단 역할 AI 분석 방식을 대체한다.

## 현재 흐름

1. 양식 등록: `export_ai_guides`가 소주제와 작성요령의 원문 위치만 추출한다. 응답에는 본문/개인정보 역할 분류, 점수, 공통/개별 분류, 새 본문이 없다.
2. 프로그램이 소주제와 원문 작성요령을 MD/위치 기록으로 저장하고, 안전한 빈칸/본문 표시를 지역적으로 연결한다. 개인정보는 알려진 정확한 항목명에만 연결하며 숫자·서명 등의 불명확한 칸은 보존한다.
3. 작성 주제와 세부 내용을 사용자가 입력하고 시작을 누른다.
4. 기존 작성 서비스가 해당 소주제/작성요령/사용자 내용을 자료조사에 전달한다. 출처·조사 결과를 본문 작성에 전달하고 결과를 원래 서식의 연결 위치에 반영한다.
5. 원본 사본과 MD는 유지한다. 출력에서는 제목/복합 요소와 연결되지 않은 안내를 보존하고, 별도로 확인된 작성요령 문구만 기존 정책대로 비운다. 최종 한글 저장/검사/자동 열기는 유지한다.

등록과 재연결은 새 `template_guide_registration.register_guided`를 사용한다. 기존 전체 문단 역할 분석기와 제한된 제목 후보/점수 기반 분석기는 이 등록 경로에서 호출하지 않는다. 기존 양식과 작업은 덮어쓰지 않는다.

## 검증과 한계

- Python 105개 테스트 통과. 등록 요청 스키마가 소주제/작성요령 전용인지 검사한다. 모의 AI를 사용하여 작성 주제·요령 → 조사 → 조사 결과가 포함된 본문 요청 → 출력 파일 흐름을 검증했다.
- 화면 콜백 검사: 등록 이후 작성 안내로 이어지고 MD 추출과 등록이 서로 다른 요청을 사용함을 확인했다.
- 기존 실제 기후부 AI 추출 기록을 추가 AI 호출 없이 읽어 로컬 연결을 검사했다: 본문 위치 563개(표 안 357개), 개인정보 위치 70개. 요령 문단과 입력 위치의 중복 0개. 입력 위치 없는 제목 68개는 수동 확인 대상으로 유지한다. 모든 소주제의 자동 작성을 보장하지 않는다.
- 이번 턴에 새로운 사용자 문서를 외부 AI에 보내거나 실제 본문을 재생성하지는 않았다. 위 조사/작성 순서 테스트는 모의 연결을 사용했다.
- 새 코드 적용은 다음 프로그램 실행부터이며 기존 등록본은 재연결해야 새 등록 모드를 사용한다.
