# 새 양식 AI 분석 중복 처리 축소

## 변경

- 원문을 `text`와 `runs`로 두 번 전달하던 방식 대신, 원문 한 번과 색상 위치 범위를 전달한다. 저장되는 원본 분석 자료는 그대로다.
- 분석 대상 전체를 참고 문맥으로 다시 전달하지 않는다. 재검토 요청에도 해당 위치 주변의 문맥만 전달한다. 긴 문맥·작성요령은 잘라내지 않는다.
- 글 없는 복합 요소 틀은 프로그램에서 원본 유지로 확정한다. 표의 자식 문단·입력 가능한 빈칸·제목·파란 주석은 분석한다.
- 응답 검사를 항목별로 수행한다. 누락·중복·불확실 항목만 한 번 다시 요청한다. 응답의 잘못된 외부 위치는 채택하지 않는다.
- 재검토가 실패해도 이미 확정된 문단의 역할·조건은 보존한다. 불확실했던 유효 응답도 원문과 함께 보존하여 사용자가 확인할 수 있게 한다.
- 고정 문구·빈칸 유지 항목에는 불필요한 설명을 반복하지 않도록 요청한다.
- 진행 메시지에 분석 대상·완료·재검토 개수를 표시한다.
- 프로그램이 보존한 틀 때문에 비어 있는 작성 주제가 추가되지 않도록 했다.

## 확인

- 관련 자동 시험 106개 통과: 양식 분석 19개, 연결 어댑터·자료 조사·문서 작성·작업 흐름·입력 검증·개인 표 화면 회귀 시험 포함.
- 분석 시험: 여러 표와 본문 혼합, 파란 조건과 제목 혼합, 빈 개인 정보 칸, 원문 번호 전체 유지, 부분 오류, 재검토 실패/성공, 중단, 저장 무결성, 긴 작성요령 문맥 보존을 확인했다.
- `development/tools/benchmark_template_analysis.py`는 외부 AI에 연결하지 않고 같은 모의 응답으로 요청량을 비교한다. 원문 파일을 변경하지 않고 수치만 보고서에 저장한다.

| 모의 비교 | 변경 전 요청 | 변경 후 요청 | 전송 데이터 문자 수 감소 |
| --- | ---: | ---: | ---: |
| 긴 작성요령 70문단 | 4 | 2 | 75.9% |
| 같은 예제에서 1항목 재검토 | 5 | 3 | 78.1% |
| 기존 기후부 양식 7,419문단 | 106 | 105 | 72.2% |

기후부 양식은 124개의 글 없는 복합 요소 틀을 프로그램이 보존하고 나머지 7,295문단을 분석 대상으로 유지한다. 모든 원문 위치는 결과에 남는다. 재검토 예제에서 이전 방식은 총 86개 항목을 요청하지만 새 방식은 71개만 요청한다.

## 범위와 한계

위 수치는 **프롬프트의 원문·문맥 데이터 문자 수**이며 토큰 수, 비용 또는 실제 AI 응답 시간의 실측이 아니다. 큰 양식에서는 요청 횟수와 분류 응답량이 여전히 많을 수 있다. 입력 가능한 빈칸을 여백으로 추측해 제거하지 않았다.

이번 변경의 실제 외부 AI 왕복 시험·한글 프로그램 출력 시험은 실행하지 않았다. 기존 등록본과 진행 중 작업을 바꾸거나 재분석하지 않았고, 사용자 프로그램을 강제 종료·재실행하지 않았다. 새 코드로 프로그램을 다시 실행한 뒤 새로 등록하는 양식에 적용된다.
