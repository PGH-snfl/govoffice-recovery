# 동일 양식의 AI 분석 경로 비교

실행일: 2026-09-28

## 비교 조건

- 동일 원문: 「연구개발제안서 · 저장응답 재사용용」의 한글 원문 사본
- 동일한 연결 계정·모델 설정으로 두 경로를 연속 실행
- 대조 기준: 기존 등록본의 주제 38개, 작성요령 위치 71개, 본문 입력 위치 138개, 개인정보 입력 위치 31개
- 원문은 772개 문단이고, 그중 내용이 있는 문단은 443개
- ‘일치율’은 기존 등록본과 같은 원문 위치를 찾은 비율이다. 기존 등록본이 절대적인 정답임을 뜻하지는 않는다.

## 결과

| 측정 항목 | 전체 문단을 AI에 전달 | 프로그램 선추출 후 AI |
|---|---:|---:|
| AI 요청 수 | 1회 | 2회 |
| AI에 보낸 요청 글자 수 합계 | 17,812자 | 7,353자 |
| AI 응답 JSON 글자 수 합계 | 2,120자 | 2,721자 |
| AI에 보낸 후보 문단 | 443개 | 74개 |
| 주제 제목 | 37/38 일치 (재현율 97.4%) | 27/38 일치 (재현율 71.1%) |
| 작성요령 위치 | 70/71 일치, 오연결 16개 (정밀도 81.4%) | 43/71 일치, 오연결 2개 (정밀도 95.6%) |
| 본문 입력 위치 | 98/138 일치 | 2/138 일치 |
| 개인정보 입력 위치 | 31/31 일치 | 31/31 일치 |

요청 글자 수 기준으로 선추출 경로는 약 58.7% 적은 내용을 보냈다. 대신 요청은 한 번 더 발생했고 응답은 더 길었다. 글자 수는 실제 토큰 수나 크레딧이 아니다.

## 해석

- 전체 문단 전달 방식은 주제와 작성요령을 더 넓게 찾았다. 다만 작성요령 표 위치 16개를 추가로 연결해 오연결이 늘었다.
- 선추출 방식은 찾아낸 작성요령의 오연결이 적었다. 그러나 프로그램이 AI에 보낼 후보 자체를 놓쳐 주제 11개와 작성요령 28개가 기준 등록본과 일치하지 않았다.
- 본문 입력 위치는 두 경로의 로컬 판정 방법도 달라 직접 비교에 주의가 필요하다. 그래도 현재 선추출 분석 경로가 이 양식의 본문 입력 위치를 충분히 복구하지 못한 것은 분명하다.
- 따라서 현재 선추출 구현을 그대로 등록 경로에 적용하는 것은 권장하지 않는다. 정확도를 우선하려면 프로그램이 후보를 추리되, 누락 가능성이 있는 주변 문단도 AI가 확인하고, 마지막에 원문 위치 전수 대조로 미확인 항목을 남기는 방식이 필요하다.

## 사용량 한계

코드와 이 실행 결과는 요청 횟수 및 글자 수만 기록한다. Codex의 실제 토큰·크레딧 사용량과 추론량은 이 비교 도구에서 읽어 오지 못했으므로, 금액이나 크레딧 절감률로 환산하지 않았다. 실제 계정 사용량은 연결된 계정의 사용량 화면에서 확인해야 한다.
