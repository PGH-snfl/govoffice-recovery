# 작성 글자색·표 가독성 보완

## 후속 변경: 확인 안내를 아래쪽 괄호 문단으로 분리

사용자 후속 요청에 따라 아래의 기존 '본문 중 부분 파란색' 규칙을 대체했다.

- 본문은 검은색, 확인 안내는 해당 문단 바로 아래 `(확인 필요: …)` 형태의 별도 파란 문단으로 표시한다.
- 기존 결과에 들어 있던 괄호 안내·확인 필요 문장은 삭제하지 않고 아래로 옮긴다. 문장 중간의 필수 빈값 표식을 떼면 문장이 망가지는 경우에는 그 문장 전체를 괄호 안내로 보존한다.
- 검토 사유가 인용한 본문 값은 검은색으로 그대로 두고, 사유만 아래에 표시한다. 같은 안내는 같은 문단 아래 중복 출력하지 않는다.
- 표에서는 같은 셀 안의 아래 문단으로 출력하고 줄바꿈·여백 처리를 유지한다.
- 작성 프롬프트와 한글 재열기 검증도 변경된 출력 문단을 기준으로 수정했다. 원본 입력값은 작업 로그에 남긴다.
- 관련 자동 테스트 116개 통과. 실제 한글 2쪽 예제 저장·재열기와 PDF 전 페이지 시각 검증 완료.
- 최신 예제: `readable_authoring/readable_1c7e6824/문단_표_파란검토표시_검증.hwp`
- 사용자 원본·완료 문서는 수정하지 않았다. 앱 재시작 후 새 출력부터 적용한다.

## 적용 범위

- 문서 작성 결과를 한글로 렌더링할 때 적용한다. 기존 완료 문서와 등록된 원본 양식은 변경하지 않는다.
- 생성된 글은 원래 글꼴·크기·자간을 유지하고 기본 검은색으로 출력한다.
- 확인/검토 필요 문장은 파란색으로 표시한다. 대괄호·괄호 안에 확인 표시를 작성한 경우 그 부분만 표시한다.
- 필드별 검토 사유에 정확히 인용된 본문 문구도 해당 필드에서만 파란색으로 표시한다.
- 일반적인 검토 안내, 예시·가정용 같은 단어, 다른 필드의 검토 사유는 전체 글을 파란색으로 만들지 않는다.
- 작성 요청에도 확정 문장과 확인 필요 문구를 구분하도록 지침을 추가했다.

## 표 처리

- 작성한 셀의 긴 설명: 왼쪽·위쪽 정렬. 금액·수량 등의 숫자: 오른쪽 정렬. 짧은 값: 원본 정렬 유지.
- 셀과 문단의 한 줄 압축을 해제하고 자동 줄바꿈을 적용한다. 긴 영문도 셀 폭에 맞게 줄바꿈한다.
- 불필요한 문단 들여쓰기·여백을 정리하고 글자 크기에 비례하는 줄 간격, 셀 안쪽 여백을 적용한다.
- 긴 내용을 입력한 바깥 표는 글자처럼 취급을 해제하고 본문과 겹치지 않게 배치하며 셀 내용의 다음 쪽 연결을 허용한다.
- 열 너비·병합·테두리·글자 크기를 유지한다. 추정으로 글자를 줄이거나 내용을 잘라내지 않는다.
- 중첩 표는 부모 셀 밖으로 재배치하지 않는다. 특수 중첩/세로쓰기/지나치게 좁은 양식까지 시각 검증한 것은 아니다.

## 검증

- 관련 자동 테스트 112개 통과.
- 실제 한글에서 긴 본문·혼합 검은색/파란색·금액이 포함된 2쪽 예제 생성 후 저장·재열기.
- 4개 입력 필드의 모든 값과 문단 위치, 문자별 색·크기·자간·장평, 셀 너비·정렬, 쪽 설정 재확인.
- 원본 한글 양식의 해시 불변 확인.
- 최종 PDF 2쪽을 이미지로 변환해 확인: 1~18번 항목이 페이지 간 이어지고 확인 부분만 파란색, 금액 오른쪽 정렬, 본문 누락·겹침 없음.
- 예제: `readable_authoring/readable_684da255/문단_표_파란검토표시_검증.hwp`
- 자동 검증 결과: `readable_authoring/readable_684da255/검증결과.json`
- 실행 중인 앱과 사용자가 열어 둔 문서는 종료/변경하지 않았다. 프로그램 재시작 후 새 작성 결과부터 적용한다.
