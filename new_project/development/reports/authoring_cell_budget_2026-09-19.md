# 표 크기에 맞춘 본문 분량 조절

- 새 작업의 원본 한글 양식에서 셀 너비·높이, 글자 크기, 여백과 줄 간격을 읽어 작성 분량을 계산한다.
- 같은 셀에 여러 입력 필드가 있으면 공간을 나누고, 기존 고정 문구와 직접 입력값이 차지하는 공간을 제외한다.
- AI 작성 요청에 셀별 본문 최대 글자 수·줄 수를 전달한다. 작은 칸은 핵심 구절, 큰 칸은 필요한 설명으로 작성하도록 지시한다.
- 본문 분량 초과 시 원래 답변을 포함하여 한 번 요약 재작성을 요청한다. 재작성 후에도 초과하면 오류와 원래 응답을 남기며, 문자열을 잘라 성공 처리하지 않는다.
- 개인정보·사실값·일정 표식은 본문 요약 대상에서 제외한다. 요약에서 다른 필드 값, 수치·날짜, 파란 확인 안내 또는 검토 사유가 누락·변경되면 수용하지 않는다. 모든 문장의 의미 동등성을 자동 증명하는 기능은 아니다.
- 정상 분량인 표는 원래 크기·위치 설정을 유지한다. 폰트 축소로 억지로 맞추지 않는다.
- 셀 분량은 보수적 추정이다. 필수 확인 안내 때문에 예상 높이를 넘으면 안내를 삭제하지 않고 최종 검토 사항에 표 높이 확인을 추가한다. 특수 중첩 표·세로쓰기 등 임의의 모든 양식에 대한 실제 배치 보장은 아니다.

## 검증

- 모의 에이전트로 과다 응답 → 요약 재요청 → 짧은 응답 → 출력 전체 작업 흐름 검증. 이번 검증에서는 실제 외부 AI 계정에 새 요청을 보내지 않았다.
- 실제 한글에서 짧은 본문·파란 괄호 안내·금액을 넣은 1쪽 예제 생성, 저장, 재열기 완료.
- 원본 대비 셀 너비·높이 불변, 4개 필드 값과 위치, 글자색·크기·자간, 정렬, 쪽 설정 확인.
- PDF 1쪽 시각 검증: 본문과 파란 안내 모두 셀 내부에 표시, 금액 오른쪽 정렬, 잘림·겹침 없음.
- 예제: `readable_authoring/readable_6c0c20ce/문단_표_파란검토표시_검증.hwp`
- 셀별 분량: `readable_authoring/readable_6c0c20ce/셀별분량.json`
- 한글 검증 결과: `readable_authoring/readable_6c0c20ce/검증결과.json`
- 기존 등록 양식과 완료 문서는 변경하지 않았다. 프로그램 재시작 후 새 작업에 적용한다.
