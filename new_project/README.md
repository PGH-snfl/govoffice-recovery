# 범정부오피스 새 프로젝트

이 디렉터리는 실행 파일 분석·복구 산출물과 분리된 새 개발 영역이다.
원본 복구 코드는 상위의 `recovered/`, 디스어셈블과 marshal은
`범피스1303_분석/`에 그대로 보존한다. 새 프로그램이 사용하는 검증 복구 소스는
`src/govoffice/runtime/recovered_hwp/`에 스냅샷으로 복사하며 원본과 섞지 않는다.

## 경계

```text
new_project/src/govoffice/
├─ app/                 실행 구성과 애플리케이션 상태
├─ domain/              Office 제품과 무관한 업무 모델
├─ ports/               한글 기능에 요구하는 인터페이스
├─ services/            공문 등 업무 흐름
├─ adapters/            복구 API·COM과 연결하는 유일한 경계
├─ institutions/        기관별 확장 기능
└─ presentation/        GUI가 사용하는 화면 모델
```

`domain`, `ports`, `services`에서는 `recovered` 또는 `한컴오피스`를 직접
import하지 않는다. 원본 API가 필요하면 `adapters/recovered_hwp.py`만 사용한다.

## 실행과 시험

번들 Python 3.13에서 다음처럼 실행할 수 있다.

```powershell
python new_project/run_tests.py
```

프로그램 런처는 다음 명령으로 실행한다. Windows WPF 원본 좌표형 GUI와 Python
기능 백엔드를 함께 실행하며, 한 프로세스에서 한글 연결 하나를 유지한다.

탐색기에서는 `new_project/범정부오피스_실행.cmd`를 더블클릭하면 된다.

한글 COM이 설치된 한글과 같은 권한으로 동작해야 하므로 런처는 UAC 승인 후
관리자 권한으로 한 번 재실행된다. 승인하지 않으면 한글 기능을 실행할 수 없다.

```powershell
.\범피스1303_분석\python313\python.exe new_project\run_app.py
```

GUI에는 원본 버튼 콜백이 완전하게 복원되고 오류 상태가 아닌 버튼만 표시한다.
현재 일반 기능 버튼 304개, 원본 기관 버튼 23개와 새 프로젝트 전용 서울과기대
진입 버튼 1개가 표시된다. 서울과기대는 `교직` 탭에서 접근하며 전용 기능이 없는
동안에는 연결 상태 안내 화면을 표시한다. 기관 보조 창도
원본 좌표와 PNG 실제 크기로 구성한다. 기관 고정 버튼 591개와 39개 하위 페이지의
기능 버튼 1,035개를 연결하며, 38개 페이지 전환 버튼으로 선택한 하위 페이지 하나만
표시한다. 따라서 서로 다른 하위 페이지의 로컬 좌표가 한 화면에서 겹치지 않는다.
화면 작업 영역보다 큰 창은 원본 비율을 유지한 채 자동으로 축소한다.
미복원·오류·인자 불완전 기능은 표시하지 않는다.

메인 화면 상단의 `연결된 한글 문서` 패널에서 `.hwp` 또는 `.hwpx` 파일을
프로그램 전용 문서로 불러올 수 있다. 패널은 현재 파일 제목과 전체 경로,
편집 가능/일부 편집/읽기 전용, 수정 여부, 표시/최소화 상태를 계속 갱신한다.
`화면에 표시/복원`, `최소화`, `닫기`는 이 프로그램이 직접 불러온 창에만
작동하며 사용자가 한글이나 탐색기에서 따로 연 문서는 건드리지 않는다. 다른
파일을 불러올 때 현재 문서가 수정됐다면 저장, 저장 안 함, 취소 중 하나를 먼저
선택한다. 한글에서 다른 이름으로 저장한 경우에도 새 경로를 패널에 반영한다.
선택 영역 캐시와 프리셋 검토 초안은 현재 활성 문서의 `DocumentID`에 묶인다.
따라서 다른 탭이나 출력 문서로 전환하면 이전 드래그 영역을 재사용하지 않고 다시
선택하도록 안내한다. 한글 COM 응답은 작업별로 최대 5초, 15초 또는 30초만 기다리며,
시간을 넘기면 멈춘 Python 백엔드를 제한 시간 안에 정리한다. COM 작업의 완료 여부가
모호한 타임아웃 뒤에는 같은 실행 안에서 백엔드를 재생성하지 않으며, 열린 한글 문서를
확인하고 범정부오피스를 완전히 다시 시작하도록 안내한다. 정상적인 비연결 상태에서만
사용자의 `다시 연결` 요청으로 백엔드를 시작한다.

실제 한글에서 전용 문서 열기·최소화·복원·수정 감지·폐기 종료를 다시 검증하려면
다음 도구를 실행한다. 도구는 원본 자산의 고유 임시 사본만 사용하고 기존 Hwp.exe
프로세스는 종료하지 않는다.

```powershell
.\범피스1303_분석\python313\python.exe new_project\tools\validate_managed_hwp_document.py
```

`글자` 탭의 `글자문단모양복사`는 두 단계로 동작한다. 서식을 가져올 글자나
문단에 커서를 둔 뒤 한 번 누르고, 적용할 영역을 선택한 뒤 같은 버튼을 다시
누른다. 적용 대기 중 다른 기능을 실행하면 모양 복사 상태를 자동으로 취소한다.

## 전체 디자인 서식 프리셋

`교직` 탭의 `서울과기대` 기관 화면에 있는 `전체 디자인 서식 프리셋` 버튼은
이미 작성된 한글 문서에서 사용자가 선택한 영역을 재사용 가능한 서식으로 저장한다. 현재 이
기능은 서울과학기술대학교 기관 전용 기능으로 등록되어 공통 상단에는 노출되지
않는다.

```text
한글에서 복사할 문단·표·개체 영역 선택
→ 교직 → 서울과기대 → 전체 디자인 서식 프리셋
→ 이름 입력
→ 선택 영역 저장
→ 목록에서 새 문서로 복제
```

선택 영역은 `HWPML2X + saveblock`으로 가져온다. 선택 밖의 본문은 저장하지
않으며, 선택 영역의 글꼴·크기·색상·문단 정렬, 표, 셀 크기, 테두리, 배경,
병합과 개체 구조를 그대로 둔다. 선택 영역이 속한 구역의 용지 크기·방향,
여백, 머리말·꼬리말 간격과 쪽 설정도 함께 보존한다. 출력할 때는 원본 문서를
건드리지 않고 선택 영역만 들어간 새 한글 문서를 만든다.
사용자 탭에 저장값이 하나도 없으면 선택 영역의 제목·본문·이름·전화번호·날짜와
빈칸을 모두 원본 그대로 저장한다. 저장값이 있으면 표 위의 연속된 제목·부제·역할
문맥(최대 3단계)과 표 안의 가로·세로·혼합 배치를 함께 읽어 필드/값 후보를 보여
준다. 이전 표·쪽/단/구역 나눔·머리말·도형·긴 본문은 문맥 경계로 처리한다. 사용자가
체크하거나 직접 드래그해 지정한 정확한 값 위치만 입력 필드로 바꾸며, 같은
문자열이 다른 역할에 쓰인 경우에도 위치별 대표필드가 서로 섞이지 않는다.
한 값이 여러 글자 서식 런에 걸쳐 있어도 원래 런 경계를 보존한다. 저장 파일은
`config/style_presets/`에 선택 영역 `.hml`과 프리셋 정의 `.json`으로 나뉘며
두 파일은 한 쌍으로 원자적으로 저장된다.

실제 한글 COM 왕복 검증은 다음 도구로 다시 실행할 수 있다.

```powershell
.\범피스1303_분석\python313\python.exe new_project\tools\validate_style_preset.py
```

이 검증기는 GUI와 동시에 실행되지 않도록 같은 단일 실행 잠금을 사용하고, 실행 전후
`Hwp.exe`의 PID와 시작 시각 및 원본·출력 `DocumentID`를 확인한다. 검증기가 만든
출력 문서는 정확히 활성화한 뒤 ID를 다시 대조해 닫고, 마지막 원본 한 개는 저장
질문이 나오지 않게 만든 뒤 격리 인스턴스의 `Quit`으로 종료한다. 프로세스 종료까지
확인하며, 동시에 존재하는 한글
프로세스는 최대 10개로 제한한다. 소유권이 모호하면 사용자 문서에는 종료 명령을
보내지 않고 검증을 중단한다.

## 개인 탭과 자동 입력

`개인` 탭은 기관 정보와 분리된 사용자 전용 영역이다. 상단 고정 정보는 이름,
전화번호, 이메일 세 개뿐이다. 첫 화면에는 실제 출력에 사용될 현재 저장값을
먼저 보여 주고, 수정·새 값 입력 버튼에서 관리 화면으로 이동한다. 그 밖의
정보는 `필드 이름`과 `입력값`의 관계로 저장한다. 대표필드에는 여러 별칭과 여러
입력값을 둘 수 있고 기본 출력값도 지정할 수 있다. 같은 입력값을 책임자·연구자처럼
서로 다른 대표필드에 동시에 연결할 수도 있다. 문서에서 별칭이 발견되면 안정
필드 ID를 통해 대표필드로 연결하며 정확히 같은 필드명·입력값 쌍만 중복에서
제외한다. 내부 전용 환경을 기준으로 값은
`config/user_profile.json`에 저장되며 배포·버전관리 대상에서는 제외한다.

전체 디자인 서식 프리셋을 저장할 때 선택 영역과 등록값을 비교한 결과를 확인
화면에 표시한다. 등록값과 일치한 항목, 아직 저장하지 않은 추천 항목을 구분해
보여 주며 사용자가 체크한 항목만 입력 필드로 분리한다. 후보에 없는 값은 한글에서
그 값만 다시 드래그해 정확 위치 후보로 추가할 수 있다. 사용자 저장값 자체가
없으면 추측 필드를 만들지 않고 원본 전체를 그대로 저장한다. 출력할 때는 필드마다
저장된 값 목록에서 하나를 고르거나 직접 입력한 뒤 새 문서를 생성한다.

콘솔 런처가 필요하면 `--cli`를 붙인다. 콘솔에서는 `list [검색어] [개수]`,
`connect`, `run 기능명 [JSON배열]`, `exit` 명령을 사용한다.

```powershell
.\범피스1303_분석\python313\python.exe new_project\run_app.py --list --search 표 --limit 20
```

복구 원본이 갱신된 경우에만 아래 동기화 도구를 실행한다. 도구는 검증 완료 기능과
별도 분류 기능을 서로 다른 JSON 카탈로그로 생성한다.

```powershell
python new_project/tools/sync_recovered_hwp.py
```

```text
src/govoffice/runtime/recovered_hwp/
├─ 한컴오피스/                  복사된 실행 소스
└─ catalog/
   ├─ verified_methods.json    런처 실행 허용 기능
   ├─ deferred_methods.json    번역·전용 검증 필요 기능
   └─ snapshot.json            복사 시점 집계
```

## 기관탭 즐겨찾기

기관탭은 다음 두 영역으로 구성한다.

```text
기관탭
├─ 즐겨찾기 · 한글 기본 기능    사용자가 저장하고 순서를 변경
└─ 기관 자체 기능              선택한 기관 라이브러리에서 제공
```

즐겨찾기는 `config/favorites.json`에 저장한다. 한글 기본 기능과 기관 기능을
같은 즐겨찾기에 추가할 수 있고, 드래그 결과를 `즐겨찾기서비스.이동()`으로
반영한다. 화면 계층은 `presentation/institution_tab.py`, 저장 구현은
`adapters/json_favorites.py`에 분리되어 있다.

## 기관 패키지

기존 메인 코드에서 분리한 기관 기능은 다음 위치에 보관한다.

```text
src/govoffice/institutions/
├─ catalog.py
└─ packages/
   ├─ seoul/
   │  ├─ manifest.json
   │  ├─ icons/
   │  └─ templates/
   ├─ sejong/
   ├─ chungnam/
   ├─ ...
   └─ seoultech/
```

- 등록 기관: 24개
- 정리된 기관 기능: 503개
- 인자 없이 화면에서 바로 실행 가능: 200개
- 원본 UI 인자 어댑터가 필요한 기능: 303개

기관 manifest는 복구 패키지를 직접 import하지 않고 실행할 한글 메서드명과
화면 노출 정보를 도메인 모델로 변환한다. 실제 원본 호환 API 호출은
`adapters/recovered_hwp.py` 경계를 통해서만 수행한다.
