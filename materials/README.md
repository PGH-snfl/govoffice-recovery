# 사용자 문서와 참고자료

파일 종류보다 **사용 목적**으로 구분한다. 2026-09-29 이동 전후 파일 내용 일치를 확인했다. 문서 본문은 수정하지 않았다.

GitHub 공유본에는 안내, 기존 기능 예시 2개, 기본 빈 신청양식만 포함한다. 실제 작업 문서·첨부·작성 결과는 소유자 PC에만 보존한다. 아래 표는 로컬의 전체 분류이며 내려받은 저장소에는 일부 안내만 있을 수 있다.

| 폴더 | 내용 | 이전 위치 |
|---|---|---|
| [examples](examples/) | 기능 확인용 예시와 문서 서식 보정본 | `예시 문서/`, 루트의 `범피스 예시1.hwp`, `범피스 예시2.hwp` |
| [submission-reference](submission-reference/) | 사업 제출서류·매뉴얼·참고자료 | `3. 제출서류 및 참고/` |
| [attachments](attachments/) | 신청서식, 관련 규정, 접수 안내와 기존 진단 자료 | `첨부자료/` |
| [validation](validation/) | 실제 문서 작성 검증에 사용한 양식과 결과 | `AI 문서 작성 실검증 결과/` |

과거 로그·출처·최근 파일 목록에는 이전 경로가 남을 수 있다. 탐색기 바로가기나 한글의 최근 문서로 열리지 않으면 이 폴더에서 다시 선택한다. 프로그램이 등록·복사한 양식과 작업 데이터는 `new_project/config/`에 유지하며 이번에 수정하지 않았다.

## 보관 원칙

- 사용자 원본과 최종 검토본은 임시파일로 취급하지 않는다.
- 신규 예시 문서는 `examples/`, 받은 양식·공고 자료는 `submission-reference/`, 기타 첨부는 `attachments/`, 실검증 산출물은 `validation/`에 저장한다.
- 이름이 ‘최종본’이어도 제출 자격·사실 검증 완료를 보장하지 않는다.
- 실제 문서에 개인정보가 포함될 수 있다. GitHub에 올릴 때는 개별 포함 여부를 확인한다. `validation/양식/`에는 약 165.5MB 한글 문서도 보존돼 있다.
